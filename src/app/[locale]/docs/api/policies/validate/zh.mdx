# 验证策略存在

检查由模块和函数名标识的策略是否已部署且可调用。此端点不执行任何策略逻辑；仅确认策略已注册且处于可运行状态。

可用此端点为评估请求做预检、确认部署成功，或为关键策略实现健康检查。

## 端点

`POST /api/v1/policies/validate`

## 必需角色

`MEMBER`

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `Content-Type` | `application/json` | 是 |
| `X-Tenant-ID` | 租户标识符字符串 | 是 |

## 请求体

```json
{
  "policyModule": "string",
  "policyFunction": "string"
}
```

| 字段 | 类型 | 必需 | 描述 |
|-------|------|----------|-------------|
| `policyModule` | `string` | 是 | 要查找的完全限定模块名（如 `"Loan.Approval"`）。 |
| `policyFunction` | `string` | 是 | 模块内要验证的函数名（如 `"isEligible"`）。 |

## 响应体

```json
{
  "valid": true,
  "error": null
}
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `valid` | `boolean` | 若策略存在、已部署且可调用则为 `true`。未找到、处于失败的部署状态或其他不可调用情形为 `false`。 |
| `error` | `string \| null` | `valid` 为 `false` 时的描述性原因；`valid` 为 `true` 时为 `null`。 |

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 验证检查完成。`200` 响应配合 `valid: false` 表示策略不存在或不可调用 —— 这是一次成功的检查，不是 HTTP 错误。 |
| `400 Bad Request` | 请求体格式错误或缺少必需字段。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少 `MEMBER` 角色。 |
| `500 Internal Server Error` | 非预期的引擎故障导致检查未能完成。 |

## 示例

<CodeGroup>

```bash [curl]
curl -X POST https://policy.aster-lang.dev/api/v1/policies/validate \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: acme-corp" \
  -d '{
    "policyModule": "Loan.Approval",
    "policyFunction": "isEligible"
  }'
```

```js [JavaScript]
const response = await fetch(
  'https://policy.aster-lang.dev/api/v1/policies/validate',
  {
    method: 'POST',
    headers: {
      Authorization: 'Bearer <token>',
      'Content-Type': 'application/json',
      'X-Tenant-ID': 'acme-corp',
    },
    body: JSON.stringify({
      policyModule: 'Loan.Approval',
      policyFunction: 'isEligible',
    }),
  }
);

const data = await response.json();

if (!data.valid) {
  console.error('Policy is not callable:', data.error);
} else {
  console.log('Policy is ready for evaluation.');
}
```

</CodeGroup>

### 示例响应（策略存在）

```json
{
  "valid": true,
  "error": null
}
```

### 示例响应（策略未找到）

```json
{
  "valid": false,
  "error": "No deployed policy found for module 'Loan.Approval', function 'isEligible'"
}
```

### 示例响应（策略处于失败状态）

```json
{
  "valid": false,
  "error": "Policy 'Loan.Approval.isEligible' exists but failed to load: compilation error in version 3"
}
```
