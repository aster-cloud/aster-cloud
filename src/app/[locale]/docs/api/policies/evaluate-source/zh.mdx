# 从源代码评估策略

即时编译并评估 CNL（受控自然语言）策略源代码字符串，无需先部署策略。可选地返回完整决策追踪以便调试。

## 端点

`POST /api/v1/policies/evaluate-source`

## 必需角色

`MEMBER`

## 查询参数

| 参数 | 类型 | 默认值 | 描述 |
|-----------|------|---------|-------------|
| `trace` | `boolean` | `false` | 当为 `true` 时，响应包含一个结构化的 `decisionTrace` 对象，显示哪些规则触发以及结果如何推导。 |

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Content-Type` | `application/json` | 是 |
| `X-Tenant-Id` | 租户标识符字符串 | 是 |
| `X-Aster-Signature` | HMAC-SHA256 十六进制签名 | 是 |
| `X-Aster-Nonce` | 随机字符串（16+ 字节十六进制或 UUID） | 是 |
| `X-Aster-Timestamp` | Unix 时间戳（**毫秒**） | 是 |
| `X-User-Role` | 调用者角色（`MEMBER`、`ADMIN`、`OWNER`） | 是 |
| `X-User-Id` | 用于审计日志的调用者标识符 | 否 |

HMAC 签名计算细节参阅 [认证](/zh/docs/getting-started/authentication)。

## 请求体

```json
{
  "source": "string",
  "context": {},
  "locale": "en-US",
  "functionName": "evaluate"
}
```

| 字段 | 类型 | 必需 | 描述 |
|-------|------|----------|-------------|
| `source` | `string` | 是 | 原始 CNL 策略源代码文本。引擎在评估前解析、规范化并编译此字符串。解析错误在 `error` 字段返回。 |
| `context` | `object` | 是 | 单个上下文对象，其键映射到目标函数声明的参数名。对于多参数函数，将每个参数包装在其声明的参数名下。 |
| `locale` | `string` | 否 | 标识 `source` 中使用的 CNL 关键字集的 BCP 47 locale 标签。默认为 `"en-US"`。简体中文 CNL 语法使用 `"zh-CN"`。 |
| `functionName` | `string` | 否 | 要在编译模块内调用的函数名。默认为 `"evaluate"`。如果源代码只定义了一个函数，则无论此值如何都会调用该函数。 |

## 响应体

```json
{
  "result": "<any>",
  "executionTimeMs": 0,
  "error": null,
  "decisionTrace": null
}
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `result` | `any` | 被评估函数返回的值。 |
| `executionTimeMs` | `number` | 总挂钟时间（毫秒），包括编译和执行。 |
| `error` | `string \| null` | 解析、编译或运行时错误消息；成功时为 `null`。 |
| `decisionTrace` | `object \| null` | 仅当设置 `?trace=true` 时存在。包含模块名、函数名和记录规则评估的有序追踪步骤列表。未启用追踪时为 `null`。 |

### 决策追踪结构

使用 `?trace=true` 时，`decisionTrace` 具有以下形状：

```json
{
  "moduleName": "string",
  "functionName": "string",
  "steps": [
    {
      "sequence": 1,
      "expression": "string",
      "result": "<any>",
      "matched": true,
      "children": []
    }
  ],
  "finalResult": "<any>",
  "executionTimeMs": 0
}
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `moduleName` | `string` | 被评估模块的名称。 |
| `functionName` | `string` | 被调用函数的名称。 |
| `steps` | `TraceStep[]` | 有序的评估步骤列表。 |
| `finalResult` | `any` | 评估的最终结果。 |
| `executionTimeMs` | `number` | 评估时间（毫秒）。 |

每个 `TraceStep` 包含：

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `sequence` | `number` | 步骤编号（从 1 开始）。 |
| `expression` | `string` | 规则或表达式描述。 |
| `result` | `any` | 此步骤的评估结果。 |
| `matched` | `boolean` | 此分支是否为最终匹配。 |
| `children` | `TraceStep[]` | 分支逻辑（if/else、match）的嵌套子步骤。 |

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 已尝试编译和评估。检查 `error` 确认是否有编译期或运行时故障。 |
| `400 Bad Request` | 请求体格式错误、缺少必需字段或 `X-Tenant-Id` 无效。 |
| `401 Unauthorized` | 缺少或无效的 HMAC 签名请求头，或时间戳超出 5 分钟重放窗口。 |
| `403 Forbidden` | HMAC 有效但调用者缺少 `MEMBER` 角色。 |
| `409 Conflict` | nonce 在重放窗口内已被使用。 |
| `500 Internal Server Error` | 非预期的引擎故障。 |

## 示例

### 无追踪

<CodeGroup>

```bash [curl]
TENANT_ID="acme-corp"
TIMESTAMP=$(($(date +%s) * 1000))
NONCE=$(openssl rand -hex 16)
BODY='{"source":"Module Discount.\n\nRule calculate given order as Order, produce Int:\n  If order.total greater than 100\n    Return 10.\n  Return 0.","context":{"order":{"total":150}},"locale":"en-US","functionName":"calculate"}'
API_SECRET="your-api-secret-here"
METHOD="POST"
PATH_URI="/api/v1/policies/evaluate-source"
QUERY=""

BODY_HASH=$(printf '%s' "${BODY}" | openssl dgst -sha256 | awk '{print $2}')
CANONICAL="${METHOD}|${PATH_URI}|${QUERY}|${TIMESTAMP}|${NONCE}|${BODY_HASH}"
SIGNATURE=$(printf '%s' "${CANONICAL}" | openssl dgst -sha256 -hmac "${API_SECRET}" | awk '{print $2}')

curl -X POST "https://policy.aster-lang.dev${PATH_URI}" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-Id: ${TENANT_ID}" \
  -H "X-User-Role: MEMBER" \
  -H "X-Aster-Signature: ${SIGNATURE}" \
  -H "X-Aster-Nonce: ${NONCE}" \
  -H "X-Aster-Timestamp: ${TIMESTAMP}" \
  -d "${BODY}"
```

```js [JavaScript]
const source = `Module Discount.

Define Order has total as Int.

Rule calculate given order as Order, produce Int:
  If order.total greater than 100
    Return 10.
  Return 0.`

const body = JSON.stringify({
  source,
  context: { order: { total: 150 } },
  locale: 'en-US',
  functionName: 'calculate',
})

const response = await fetch(
  'https://policy.aster-lang.dev/api/v1/policies/evaluate-source',
  {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-Tenant-Id': 'acme-corp',
      'X-User-Role': 'MEMBER',
      'X-Aster-Signature': signature,  // see Authentication docs
      'X-Aster-Nonce': nonce,
      'X-Aster-Timestamp': timestamp,
    },
    body,
  }
)

const data = await response.json()
```

</CodeGroup>

### 带决策追踪

<CodeGroup>

```bash [curl]
TENANT_ID="acme-corp"
TIMESTAMP=$(($(date +%s) * 1000))
NONCE=$(openssl rand -hex 16)
BODY='{"source":"Module Discount.\n\nDefine Order has total as Int.\n\nRule calculate given order as Order, produce Int:\n  If order.total greater than 100\n    Return 10.\n  Return 0.","context":{"order":{"total":150}},"locale":"en-US","functionName":"calculate"}'
API_SECRET="your-api-secret-here"
METHOD="POST"
PATH_URI="/api/v1/policies/evaluate-source"
QUERY="trace=true"

BODY_HASH=$(printf '%s' "${BODY}" | openssl dgst -sha256 | awk '{print $2}')
CANONICAL="${METHOD}|${PATH_URI}|${QUERY}|${TIMESTAMP}|${NONCE}|${BODY_HASH}"
SIGNATURE=$(printf '%s' "${CANONICAL}" | openssl dgst -sha256 -hmac "${API_SECRET}" | awk '{print $2}')

curl -X POST "https://policy.aster-lang.dev${PATH_URI}?${QUERY}" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-Id: ${TENANT_ID}" \
  -H "X-User-Role: MEMBER" \
  -H "X-Aster-Signature: ${SIGNATURE}" \
  -H "X-Aster-Nonce: ${NONCE}" \
  -H "X-Aster-Timestamp: ${TIMESTAMP}" \
  -d "${BODY}"
```

```js [JavaScript]

Define Order has total as Int.

  If order.total greater than 100
    Return 10.
  Return 0.`

  source,

  'https://policy.aster-lang.dev/api/v1/policies/evaluate-source?trace=true',

```
