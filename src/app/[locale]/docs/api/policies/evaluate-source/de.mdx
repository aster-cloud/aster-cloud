# Policy aus Quellcode evaluieren

Kompilieren und evaluieren Sie eine CNL-Policy-Quellcode-Zeichenkette (Controlled Natural Language) ad hoc, ohne dass die Policy zuvor bereitgestellt werden muss. Liefert optional einen vollständigen Decision-Trace für das Debugging.

## Endpunkt

`POST /api/v1/policies/evaluate-source`

## Erforderliche Rolle

`MEMBER`

## Query-Parameter

| Parameter | Typ | Standard | Beschreibung |
|-----------|------|---------|-------------|
| `trace` | `boolean` | `false` | Wenn `true`, enthält die Antwort ein strukturiertes `decisionTrace`-Objekt, das zeigt, welche Regeln gefeuert haben und wie das Ergebnis abgeleitet wurde. |

## Header

| Header | Wert | Erforderlich |
|--------|-------|----------|
| `Content-Type` | `application/json` | Ja |
| `X-Tenant-Id` | Mandanten-Identifikator-String | Ja |
| `X-Aster-Signature` | HMAC-SHA256 Hex-Signatur | Ja |
| `X-Aster-Nonce` | Zufallsstring (16+ Bytes Hex oder UUID) | Ja |
| `X-Aster-Timestamp` | Unix-Zeitstempel in **Millisekunden** | Ja |
| `X-User-Role` | Rolle des Aufrufers (`MEMBER`, `ADMIN`, `OWNER`) | Ja |
| `X-User-Id` | Aufrufer-Bezeichner für Audit-Logs | Nein |

Details zur Berechnung der HMAC-Signatur siehe [Authentifizierung](/de/docs/getting-started/authentication).

## Request-Body

```json
{
  "source": "string",
  "context": {},
  "locale": "en-US",
  "functionName": "evaluate"
}
```

| Feld | Typ | Erforderlich | Beschreibung |
|-------|------|----------|-------------|
| `source` | `string` | Ja | Roher CNL-Policy-Quellcode-Text. Die Engine parst, kanonisiert und kompiliert diesen String vor der Evaluierung. Parsing-Fehler werden im `error`-Feld zurückgegeben. |
| `context` | `object` | Ja | Ein einzelnes Kontext-Objekt, dessen Schlüssel den deklarierten Parameternamen der Zielfunktion entsprechen. Bei Mehr-Parameter-Funktionen jedes Argument unter seinem deklarierten Parameternamen einwickeln. |
| `locale` | `string` | Nein | BCP-47-Locale-Tag, das den in `source` verwendeten CNL-Schlüsselwortsatz identifiziert. Standard: `"en-US"`. Verwenden Sie `"zh-CN"` für vereinfachten chinesischen CNL-Syntax. |
| `functionName` | `string` | Nein | Name der innerhalb des kompilierten Moduls aufzurufenden Funktion. Standard: `"evaluate"`. Wenn die Quelle nur eine Funktion definiert, wird diese unabhängig von diesem Wert aufgerufen. |

## Response-Body

```json
{
  "result": "<any>",
  "executionTimeMs": 0,
  "error": null,
  "decisionTrace": null
}
```

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `result` | `any` | Der von der evaluierten Funktion zurückgegebene Wert. |
| `executionTimeMs` | `number` | Gesamte Wanduhrzeit in Millisekunden einschließlich Kompilierung und Ausführung. |
| `error` | `string \| null` | Parse-, Kompilierungs- oder Laufzeit-Fehlermeldung; `null` bei Erfolg. |
| `decisionTrace` | `object \| null` | Nur vorhanden, wenn `?trace=true` gesetzt ist. Enthält den Modulnamen, Funktionsnamen und eine geordnete Liste von Trace-Schritten, die die Regelevaluierung aufzeichnen. `null`, wenn Tracing deaktiviert ist. |

### Decision-Trace-Struktur

Bei Verwendung von `?trace=true` hat `decisionTrace` die folgende Form:

```json
{
  "moduleName": "string",
  "functionName": "string",
  "steps": [
    {
      "sequence": 1,
      "expression": "string",
      "result": "<any>",
      "matched": true,
      "children": []
    }
  ],
  "finalResult": "<any>",
  "executionTimeMs": 0
}
```

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `moduleName` | `string` | Der Name des evaluierten Moduls. |
| `functionName` | `string` | Der Name der aufgerufenen Funktion. |
| `steps` | `TraceStep[]` | Geordnete Liste der Evaluierungsschritte. |
| `finalResult` | `any` | Das Endergebnis der Evaluierung. |
| `executionTimeMs` | `number` | Evaluierungszeit in Millisekunden. |

Jeder `TraceStep` enthält:

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `sequence` | `number` | Schritt-Nummer (beginnend bei 1). |
| `expression` | `string` | Die Regel- oder Ausdrucksbeschreibung. |
| `result` | `any` | Das evaluierte Ergebnis dieses Schritts. |
| `matched` | `boolean` | Ob dieser Zweig das finale Match war. |
| `children` | `TraceStep[]` | Verschachtelte Unter-Schritte für Verzweigungslogik (if/else, match). |

## HTTP-Statuscodes

| Status | Bedeutung |
|--------|---------|
| `200 OK` | Kompilierung und Evaluierung versucht. Prüfen Sie `error` auf Kompilierungs- oder Laufzeit-Fehler. |
| `400 Bad Request` | Fehlerhafter Request-Body, fehlende Pflichtfelder oder ungültige `X-Tenant-Id`. |
| `401 Unauthorized` | Fehlende oder ungültige HMAC-Signatur-Header oder Zeitstempel außerhalb des 5-Minuten-Replay-Fensters. |
| `403 Forbidden` | HMAC ist gültig, dem Aufrufer fehlt jedoch die `MEMBER`-Rolle. |
| `409 Conflict` | Nonce wurde bereits innerhalb des Replay-Fensters verwendet. |
| `500 Internal Server Error` | Unerwarteter Engine-Fehler. |

## Beispiele

### Ohne Trace

<CodeGroup>

```bash [curl]
TENANT_ID="acme-corp"
TIMESTAMP=$(($(date +%s) * 1000))
NONCE=$(openssl rand -hex 16)
BODY='{"source":"Module Discount.\n\nRule calculate given order as Order, produce Int:\n  If order.total greater than 100\n    Return 10.\n  Return 0.","context":{"order":{"total":150}},"locale":"en-US","functionName":"calculate"}'
API_SECRET="your-api-secret-here"
METHOD="POST"
PATH_URI="/api/v1/policies/evaluate-source"
QUERY=""

BODY_HASH=$(printf '%s' "${BODY}" | openssl dgst -sha256 | awk '{print $2}')
CANONICAL="${METHOD}|${PATH_URI}|${QUERY}|${TIMESTAMP}|${NONCE}|${BODY_HASH}"
SIGNATURE=$(printf '%s' "${CANONICAL}" | openssl dgst -sha256 -hmac "${API_SECRET}" | awk '{print $2}')

curl -X POST "https://policy.aster-lang.dev${PATH_URI}" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-Id: ${TENANT_ID}" \
  -H "X-User-Role: MEMBER" \
  -H "X-Aster-Signature: ${SIGNATURE}" \
  -H "X-Aster-Nonce: ${NONCE}" \
  -H "X-Aster-Timestamp: ${TIMESTAMP}" \
  -d "${BODY}"
```

```js [JavaScript]
const source = `Module Discount.

Define Order has total as Int.

Rule calculate given order as Order, produce Int:
  If order.total greater than 100
    Return 10.
  Return 0.`

const body = JSON.stringify({
  source,
  context: { order: { total: 150 } },
  locale: 'en-US',
  functionName: 'calculate',
})

const response = await fetch(
  'https://policy.aster-lang.dev/api/v1/policies/evaluate-source',
  {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-Tenant-Id': 'acme-corp',
      'X-User-Role': 'MEMBER',
      'X-Aster-Signature': signature,  // see Authentication docs
      'X-Aster-Nonce': nonce,
      'X-Aster-Timestamp': timestamp,
    },
    body,
  }
)

const data = await response.json()
```

</CodeGroup>

### Mit Decision-Trace

<CodeGroup>

```bash [curl]
TENANT_ID="acme-corp"
TIMESTAMP=$(($(date +%s) * 1000))
NONCE=$(openssl rand -hex 16)
BODY='{"source":"Module Discount.\n\nDefine Order has total as Int.\n\nRule calculate given order as Order, produce Int:\n  If order.total greater than 100\n    Return 10.\n  Return 0.","context":{"order":{"total":150}},"locale":"en-US","functionName":"calculate"}'
API_SECRET="your-api-secret-here"
METHOD="POST"
PATH_URI="/api/v1/policies/evaluate-source"
QUERY="trace=true"

BODY_HASH=$(printf '%s' "${BODY}" | openssl dgst -sha256 | awk '{print $2}')
CANONICAL="${METHOD}|${PATH_URI}|${QUERY}|${TIMESTAMP}|${NONCE}|${BODY_HASH}"
SIGNATURE=$(printf '%s' "${CANONICAL}" | openssl dgst -sha256 -hmac "${API_SECRET}" | awk '{print $2}')

curl -X POST "https://policy.aster-lang.dev${PATH_URI}?${QUERY}" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-Id: ${TENANT_ID}" \
  -H "X-User-Role: MEMBER" \
  -H "X-Aster-Signature: ${SIGNATURE}" \
  -H "X-Aster-Nonce: ${NONCE}" \
  -H "X-Aster-Timestamp: ${TIMESTAMP}" \
  -d "${BODY}"
```

```js [JavaScript]
const source = `Module Discount.

Define Order has total as Int.

Rule calculate given order as Order, produce Int:
  If order.total greater than 100
    Return 10.
  Return 0.`

const body = JSON.stringify({
  source,
  context: { order: { total: 150 } },

const response = await fetch(
  'https://policy.aster-lang.dev/api/v1/policies/evaluate-source?trace=true',

  }

const data = await response.json()
// data.decisionTrace.steps → array of rule evaluation steps
```
