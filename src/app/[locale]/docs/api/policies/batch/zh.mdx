# 批量评估策略

在单个 HTTP 请求中评估最多 100 个策略调用。批次中的每一项都是独立的评估请求。结果按输入请求的顺序返回。单个项目的失败不会影响批次中的其他项目。

## 端点

`POST /api/v1/policies/evaluate/batch`

## 必需角色

`MEMBER`

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `Content-Type` | `application/json` | 是 |
| `X-Tenant-ID` | 租户标识符字符串 | 是 |

## 请求体

```json
{
  "requests": [
    {
      "policyModule": "string",
      "policyFunction": "string",
      "context": [{}]
    }
  ]
}
```

| 字段 | 类型 | 必需 | 描述 |
|-------|------|----------|-------------|
| `requests` | `array<EvaluationRequest>` | 是 | 评估请求的有序列表。每次调用最多 100 项。索引超过 99 的请求会以 `400` 错误被拒绝。 |

### EvaluationRequest

`requests` 的每个元素遵循与单个 `/evaluate` 请求体相同的 schema：

| 字段 | 类型 | 必需 | 描述 |
|-------|------|----------|-------------|
| `policyModule` | `string` | 是 | 已部署策略的完全限定模块名。 |
| `policyFunction` | `string` | 是 | 模块内要调用的函数名。 |
| `context` | `array<object>` | 是 | 按位置传递给函数的参数对象有序列表。 |

## 响应体

```json
{
  "responses": [
    {
      "result": "<any>",
      "executionTimeMs": 0,
      "error": null,
      "decisionTrace": null
    }
  ],
  "totalExecutionTimeMs": 0,
  "successCount": 0,
  "failureCount": 0
}
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `responses` | `array<EvaluationResponse>` | 与输入 `requests` 数组相同顺序的结果。每个请求恰好产生一个响应条目，即使评估失败。 |
| `totalExecutionTimeMs` | `number` | 所有评估加上批次协调开销的合并挂钟时间（毫秒）。 |
| `successCount` | `number` | `error` 为 `null` 的项目数量。 |
| `failureCount` | `number` | `error` 非 null 的项目数量。 |

### EvaluationResponse

`responses` 的每个元素与单个 `/evaluate` 响应具有相同的形状：

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `result` | `any` | 策略函数的返回值，若评估失败则为 `null`。 |
| `executionTimeMs` | `number` | 此独立项目的执行时间。 |
| `error` | `string \| null` | 此项目的错误消息；成功时为 `null`。 |
| `decisionTrace` | `object \| null` | 始终为 `null` —— 批量模式下不提供决策追踪。 |

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 批次已处理。检查 `failureCount` 和每项的 `error` 字段以检测单个失败。 |
| `400 Bad Request` | 请求体格式错误、`requests` 数组超过 100 项或缺少必需字段。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少 `MEMBER` 角色。 |
| `500 Internal Server Error` | 影响整个批次的非预期引擎故障。 |

## 示例

<CodeGroup>

```bash [curl]
curl -X POST https://policy.aster-lang.dev/api/v1/policies/evaluate/batch \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: acme-corp" \
  -d '{
    "requests": [
      {
        "policyModule": "Loan.Approval",
        "policyFunction": "isEligible",
        "context": [
          { "applicantAge": 30, "creditScore": 720, "requestedAmount": 25000 }
        ]
      },
      {
        "policyModule": "Discount",
        "policyFunction": "calculate",
        "context": [
          { "order": { "total": 150 } }
        ]
      },
      {
        "policyModule": "Fraud.Detection",
        "policyFunction": "riskScore",
        "context": [
          { "transaction": { "amount": 9999, "country": "US" } }
        ]
      }
    ]
  }'
```

```js [JavaScript]
const requests = [
  {
    policyModule: 'Loan.Approval',
    policyFunction: 'isEligible',
    context: [{ applicantAge: 30, creditScore: 720, requestedAmount: 25000 }],
  },
  {
    policyModule: 'Discount',
    policyFunction: 'calculate',
    context: [{ order: { total: 150 } }],
  },
  {
    policyModule: 'Fraud.Detection',
    policyFunction: 'riskScore',
    context: [{ transaction: { amount: 9999, country: 'US' } }],
  },
];

const response = await fetch(
  'https://policy.aster-lang.dev/api/v1/policies/evaluate/batch',
  {
    method: 'POST',
    headers: {
      Authorization: 'Bearer <token>',
      'Content-Type': 'application/json',
      'X-Tenant-ID': 'acme-corp',
    },
    body: JSON.stringify({ requests }),
  }
);

const data = await response.json();

console.log(`Success: ${data.successCount}, Failure: ${data.failureCount}`);

data.responses.forEach((res, i) => {
  if (res.error) {
    console.error(`Request ${i} failed: ${res.error}`);
  } else {
    console.log(`Request ${i} result:`, res.result);
  }
});
```

</CodeGroup>
