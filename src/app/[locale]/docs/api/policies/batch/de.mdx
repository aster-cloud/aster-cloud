# Policies im Batch evaluieren

Bewerten Sie bis zu 100 Policy-Aufrufe in einer einzigen HTTP-Anfrage. Jedes Element im Batch ist eine unabhängige Evaluierungsanfrage. Ergebnisse werden in derselben Reihenfolge wie die Eingabe-Anfragen zurückgegeben. Fehler in einzelnen Elementen wirken sich nicht auf den Rest des Batches aus.

## Endpunkt

`POST /api/v1/policies/evaluate/batch`

## Erforderliche Rolle

`MEMBER`

## Header

| Header | Wert | Erforderlich |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | Ja |
| `Content-Type` | `application/json` | Ja |
| `X-Tenant-ID` | Mandanten-Identifikator-String | Ja |

## Request-Body

```json
{
  "requests": [
    {
      "policyModule": "string",
      "policyFunction": "string",
      "context": [{}]
    }
  ]
}
```

| Feld | Typ | Erforderlich | Beschreibung |
|-------|------|----------|-------------|
| `requests` | `array<EvaluationRequest>` | Ja | Geordnete Liste von Evaluierungsanfragen. Maximal 100 Elemente pro Aufruf. Anfragen über Index 99 hinaus werden mit einem `400`-Fehler abgelehnt. |

### EvaluationRequest

Jedes Element von `requests` folgt demselben Schema wie der einzelne `/evaluate`-Request-Body:

| Feld | Typ | Erforderlich | Beschreibung |
|-------|------|----------|-------------|
| `policyModule` | `string` | Ja | Vollqualifizierter Modulname der bereitgestellten Policy. |
| `policyFunction` | `string` | Ja | Funktionsname innerhalb des Moduls, der aufgerufen werden soll. |
| `context` | `array<object>` | Ja | Geordnete Liste von Argument-Objekten, die positional an die Funktion übergeben werden. |

## Response-Body

```json
{
  "responses": [
    {
      "result": "<any>",
      "executionTimeMs": 0,
      "error": null,
      "decisionTrace": null
    }
  ],
  "totalExecutionTimeMs": 0,
  "successCount": 0,
  "failureCount": 0
}
```

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `responses` | `array<EvaluationResponse>` | Ergebnisse in derselben Reihenfolge wie das Eingabe-`requests`-Array. Jede Anfrage erzeugt genau einen Antwort-Eintrag, auch wenn die Evaluierung fehlschlug. |
| `totalExecutionTimeMs` | `number` | Kombinierte Wanduhrzeit in Millisekunden für alle Evaluierungen plus Batch-Koordinations-Overhead. |
| `successCount` | `number` | Anzahl der Elemente, bei denen `error` `null` ist. |
| `failureCount` | `number` | Anzahl der Elemente, bei denen `error` nicht `null` ist. |

### EvaluationResponse

Jedes Element von `responses` hat dieselbe Form wie die einzelne `/evaluate`-Antwort:

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `result` | `any` | Rückgabewert der Policy-Funktion oder `null`, falls die Evaluierung fehlschlug. |
| `executionTimeMs` | `number` | Ausführungszeit für dieses einzelne Element. |
| `error` | `string \| null` | Fehlermeldung für dieses Element; `null` bei Erfolg. |
| `decisionTrace` | `object \| null` | Immer `null` — Decision-Tracing ist im Batch-Modus nicht verfügbar. |

## HTTP-Statuscodes

| Status | Bedeutung |
|--------|---------|
| `200 OK` | Batch verarbeitet. Prüfen Sie `failureCount` und die `error`-Felder pro Element, um einzelne Fehler zu erkennen. |
| `400 Bad Request` | Fehlerhafter Request-Body, `requests`-Array überschreitet 100 Elemente oder fehlende Pflichtfelder. |
| `401 Unauthorized` | Fehlender oder ungültiger Bearer-Token. |
| `403 Forbidden` | Token ist gültig, dem Aufrufer fehlt jedoch die `MEMBER`-Rolle. |
| `500 Internal Server Error` | Unerwarteter Engine-Fehler, der den gesamten Batch betrifft. |

## Beispiele

<CodeGroup>

```bash [curl]
curl -X POST https://policy.aster-lang.dev/api/v1/policies/evaluate/batch \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: acme-corp" \
  -d '{
    "requests": [
      {
        "policyModule": "Loan.Approval",
        "policyFunction": "isEligible",
        "context": [
          { "applicantAge": 30, "creditScore": 720, "requestedAmount": 25000 }
        ]
      },
      {
        "policyModule": "Discount",
        "policyFunction": "calculate",
        "context": [
          { "order": { "total": 150 } }
        ]
      },
      {
        "policyModule": "Fraud.Detection",
        "policyFunction": "riskScore",
        "context": [
          { "transaction": { "amount": 9999, "country": "US" } }
        ]
      }
    ]
  }'
```

```js [JavaScript]
const requests = [
  {
    policyModule: 'Loan.Approval',
    policyFunction: 'isEligible',
    context: [{ applicantAge: 30, creditScore: 720, requestedAmount: 25000 }],
  },
  {
    policyModule: 'Discount',
    policyFunction: 'calculate',
    context: [{ order: { total: 150 } }],
  },
  {
    policyModule: 'Fraud.Detection',
    policyFunction: 'riskScore',
    context: [{ transaction: { amount: 9999, country: 'US' } }],
  },
];

const response = await fetch(
  'https://policy.aster-lang.dev/api/v1/policies/evaluate/batch',
  {
    method: 'POST',
    headers: {
      Authorization: 'Bearer <token>',
      'Content-Type': 'application/json',
      'X-Tenant-ID': 'acme-corp',
    },
    body: JSON.stringify({ requests }),
  }
);

const data = await response.json();

console.log(`Success: ${data.successCount}, Failure: ${data.failureCount}`);

data.responses.forEach((res, i) => {
  if (res.error) {
    console.error(`Request ${i} failed: ${res.error}`);
  } else {
    console.log(`Request ${i} result:`, res.result);
  }
});
```

</CodeGroup>
