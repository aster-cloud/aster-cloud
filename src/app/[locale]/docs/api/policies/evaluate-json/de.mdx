# Core-IR-JSON-Policy evaluieren

Evaluieren Sie eine Policy direkt als Core-IR-JSON-Objekt, ohne CNL-Parsen oder Kompilierung. Nutzen Sie diesen Endpunkt, wenn Ihre Anwendung ihre eigene Kompilierungs-Pipeline verwaltet und vorkompilierte Policy-Repräsentationen an die Engine sendet.

## Endpunkt

`POST /api/v1/policies/evaluate-json`

## Erforderliche Rolle

`MEMBER`

## Header

| Header | Wert | Erforderlich |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | Ja |
| `Content-Type` | `application/json` | Ja |
| `X-Tenant-ID` | Mandanten-Identifikator-String | Ja |

## Request-Body

```json
{
  "policy": "string (Core IR JSON)",
  "context": {}
}
```

| Feld | Typ | Erforderlich | Beschreibung |
|-------|------|----------|-------------|
| `policy` | `string` | Ja | Ein JSON-kodierter String, der die Core-IR-Repräsentation der Policy enthält. Dies ist die serialisierte Form, die von der IR-Emission-Stufe des Aster-Compilers erzeugt wird. Die Engine deserialisiert und führt diese IR direkt aus und überspringt alle CNL-Parsing-Schritte. |
| `context` | `object` | Ja | Ein einzelnes Objekt, dessen Schlüssel den deklarierten Parameternamen der Einstiegsfunktion in der Core IR entsprechen. |

### Core-IR-JSON-Format

Das `policy`-Feld muss ein als String serialisiertes JSON-Objekt sein, das dem Core-IR-Schema entspricht. Ein minimales Beispiel mit einer einzelnen Funktion:

```json
{
  "moduleName": "Discount",
  "functions": [
    {
      "name": "calculate",
      "params": [{ "name": "order", "type": "Order" }],
      "rules": [
        {
          "condition": { "op": "gt", "left": { "ref": "order.total" }, "right": { "lit": 100 } },
          "result": { "lit": 10 }
        },
        {
          "condition": null,
          "result": { "lit": 0 }
        }
      ]
    }
  ]
}
```

Wenn dies als `policy`-Feld in die Anfrage eingebettet wird, muss das Objekt JSON-stringifiziert werden (d. h. das gesamte Objekt wird zu einem String-Wert).

## Response-Body

```json
{
  "result": "<any>",
  "executionTimeMs": 0,
  "error": null,
  "decisionTrace": null
}
```

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `result` | `any` | Der von der Einstiegsfunktion in der Core IR zurückgegebene Wert. |
| `executionTimeMs` | `number` | Wanduhrzeit in Millisekunden von der IR-Deserialisierung bis zum Versand der Antwort. |
| `error` | `string \| null` | IR-Deserialisierungs- oder Laufzeit-Fehlermeldung; `null` bei Erfolg. |
| `decisionTrace` | `object \| null` | Für diesen Endpunkt immer `null`. Tracing wird für Core-IR-Evaluierung nicht unterstützt. |

## HTTP-Statuscodes

| Status | Bedeutung |
|--------|---------|
| `200 OK` | Evaluierung versucht. Prüfen Sie `error` auf IR-Parsing- oder Laufzeit-Fehler. |
| `400 Bad Request` | Fehlerhafter Request-Body, ungültiges Core-IR-JSON oder fehlende Pflichtfelder. |
| `401 Unauthorized` | Fehlender oder ungültiger Bearer-Token. |
| `403 Forbidden` | Token ist gültig, dem Aufrufer fehlt jedoch die `MEMBER`-Rolle. |
| `500 Internal Server Error` | Unerwarteter Engine-Fehler. |

## Beispiele

<CodeGroup>

```bash [curl]
curl -X POST https://policy.aster-lang.dev/api/v1/policies/evaluate-json \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: acme-corp" \
  -d '{
    "policy": "{\"moduleName\":\"Discount\",\"functions\":[{\"name\":\"calculate\",\"params\":[{\"name\":\"order\",\"type\":\"Order\"}],\"rules\":[{\"condition\":{\"op\":\"gt\",\"left\":{\"ref\":\"order.total\"},\"right\":{\"lit\":100}},\"result\":{\"lit\":10}},{\"condition\":null,\"result\":{\"lit\":0}}]}]}",
    "context": {
      "order": { "total": 150 }
    }
  }'
```

```js [JavaScript]
// Build the Core IR object
const coreIR = {
  moduleName: 'Discount',
  functions: [
    {
      name: 'calculate',
      params: [{ name: 'order', type: 'Order' }],
      rules: [
        {
          condition: { op: 'gt', left: { ref: 'order.total' }, right: { lit: 100 } },
          result: { lit: 10 },
        },
        {
          condition: null,
          result: { lit: 0 },
        },
      ],
    },
  ],
};

const response = await fetch(
  'https://policy.aster-lang.dev/api/v1/policies/evaluate-json',
  {
    method: 'POST',
    headers: {
      Authorization: 'Bearer <token>',
      'Content-Type': 'application/json',
      'X-Tenant-ID': 'acme-corp',
    },
    body: JSON.stringify({
      // Core IR must be serialized as a string
      policy: JSON.stringify(coreIR),
      context: {
        order: { total: 150 },
      },
    }),
  }
);

const data = await response.json();
// data.result → 10
```

</CodeGroup>

### Beispiel-Antwort

```json
{
  "result": 10,
  "executionTimeMs": 3,
  "error": null,
  "decisionTrace": null
}
```
