# 评估 Core IR JSON 策略

直接评估以 Core IR JSON 对象形式表达的策略，无需 CNL 解析或编译。当你的应用自行管理编译流水线并向引擎发送预编译的策略表示时，使用此端点。

## 端点

`POST /api/v1/policies/evaluate-json`

## 必需角色

`MEMBER`

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `Content-Type` | `application/json` | 是 |
| `X-Tenant-ID` | 租户标识符字符串 | 是 |

## 请求体

```json
{
  "policy": "string (Core IR JSON)",
  "context": {}
}
```

| 字段 | 类型 | 必需 | 描述 |
|-------|------|----------|-------------|
| `policy` | `string` | 是 | 包含策略 Core IR 表示的 JSON 编码字符串。这是 Aster 编译器 IR 发射阶段产生的序列化形式。引擎直接反序列化并执行此 IR，跳过所有 CNL 解析步骤。 |
| `context` | `object` | 是 | 单个对象，其键映射到 Core IR 中入口函数声明的参数名。 |

### Core IR JSON 格式

`policy` 字段必须是符合 Core IR schema 的字符串化 JSON 对象。包含单个函数的最小示例：

```json
{
  "moduleName": "Discount",
  "functions": [
    {
      "name": "calculate",
      "params": [{ "name": "order", "type": "Order" }],
      "rules": [
        {
          "condition": { "op": "gt", "left": { "ref": "order.total" }, "right": { "lit": 100 } },
          "result": { "lit": 10 }
        },
        {
          "condition": null,
          "result": { "lit": 0 }
        }
      ]
    }
  ]
}
```

将其作为请求中 `policy` 字段嵌入时，对象必须被 JSON 字符串化（即整个对象成为一个字符串值）。

## 响应体

```json
{
  "result": "<any>",
  "executionTimeMs": 0,
  "error": null,
  "decisionTrace": null
}
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `result` | `any` | Core IR 中入口函数返回的值。 |
| `executionTimeMs` | `number` | 从 IR 反序列化到响应分发的挂钟时间（毫秒）。 |
| `error` | `string \| null` | IR 反序列化或运行时错误消息；成功时为 `null`。 |
| `decisionTrace` | `object \| null` | 此端点始终为 `null`。Core IR 评估不支持追踪。 |

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 已尝试评估。检查 `error` 确认是否有 IR 解析或运行时故障。 |
| `400 Bad Request` | 请求体格式错误、Core IR JSON 无效或缺少必需字段。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少 `MEMBER` 角色。 |
| `500 Internal Server Error` | 非预期的引擎故障。 |

## 示例

<CodeGroup>

```bash [curl]
curl -X POST https://policy.aster-lang.dev/api/v1/policies/evaluate-json \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: acme-corp" \
  -d '{
    "policy": "{\"moduleName\":\"Discount\",\"functions\":[{\"name\":\"calculate\",\"params\":[{\"name\":\"order\",\"type\":\"Order\"}],\"rules\":[{\"condition\":{\"op\":\"gt\",\"left\":{\"ref\":\"order.total\"},\"right\":{\"lit\":100}},\"result\":{\"lit\":10}},{\"condition\":null,\"result\":{\"lit\":0}}]}]}",
    "context": {
      "order": { "total": 150 }
    }
  }'
```

```js [JavaScript]
// Build the Core IR object
const coreIR = {
  moduleName: 'Discount',
  functions: [
    {
      name: 'calculate',
      params: [{ name: 'order', type: 'Order' }],
      rules: [
        {
          condition: { op: 'gt', left: { ref: 'order.total' }, right: { lit: 100 } },
          result: { lit: 10 },
        },
        {
          condition: null,
          result: { lit: 0 },
        },
      ],
    },
  ],
};

const response = await fetch(
  'https://policy.aster-lang.dev/api/v1/policies/evaluate-json',
  {
    method: 'POST',
    headers: {
      Authorization: 'Bearer <token>',
      'Content-Type': 'application/json',
      'X-Tenant-ID': 'acme-corp',
    },
    body: JSON.stringify({
      // Core IR must be serialized as a string
      policy: JSON.stringify(coreIR),
      context: {
        order: { total: 150 },
      },
    }),
  }
);

const data = await response.json();
// data.result → 10
```

</CodeGroup>

### 示例响应

```json
{
  "result": 10,
  "executionTimeMs": 3,
  "error": null,
  "decisionTrace": null
}
```
