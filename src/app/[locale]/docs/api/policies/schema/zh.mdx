# 提取策略参数 Schema

解析 CNL 源代码字符串，返回指定函数的参数 schema。使用此端点在构造评估请求前发现策略期望的数据形状，或为工具中的动态表单生成提供驱动。

## 端点

`POST /api/v1/policies/schema`

## 必需角色

`MEMBER`

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `Content-Type` | `application/json` | 是 |
| `X-Tenant-ID` | 租户标识符字符串 | 是 |

## 请求体

```json
{
  "source": "string",
  "functionName": "string",
  "locale": "en-US"
}
```

| 字段 | 类型 | 必需 | 描述 |
|-------|------|----------|-------------|
| `source` | `string` | 是 | 要解析的原始 CNL 策略源代码文本。引擎从源代码中提取类型声明，不执行任何策略逻辑。 |
| `functionName` | `string` | 否 | 要提取参数 schema 的函数名。若省略，引擎提取源代码中声明的第一个函数的 schema。 |
| `locale` | `string` | 否 | 标识 CNL 关键字集的 BCP 47 locale 标签。默认为 `"en-US"`。简体中文 CNL 语法使用 `"zh-CN"`。 |

## 响应体

```json
{
  "success": true,
  "moduleName": "string",
  "functionName": "string",
  "parameters": [
    {
      "name": "string",
      "type": "string",
      "typeKind": "PRIMITIVE",
      "optional": false,
      "position": 0,
      "fields": []
    }
  ],
  "error": null
}
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `success` | `boolean` | 若源代码解析成功且 schema 提取无错完成则为 `true`。 |
| `moduleName` | `string` | 源代码中声明的模块名。 |
| `functionName` | `string` | 提取了 schema 的函数名。匹配请求中的 `functionName`，未指定时为第一个函数。 |
| `parameters` | `array<ParameterSchema>` | 参数描述符的有序列表。顺序匹配 CNL 源代码中按位置的声明顺序。 |
| `error` | `string \| null` | 当 `success` 为 `false` 时的解析错误消息；成功时为 `null`。 |

### ParameterSchema

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `name` | `string` | CNL 源代码中声明的参数名。 |
| `type` | `string` | 声明的类型名（如 `"number"`、`"boolean"`、`"string"`、`"Order"`、`"Applicant"`）。 |
| `typeKind` | `"PRIMITIVE" \| "STRUCT"` | `PRIMITIVE` 表示内建标量类型（`number`、`boolean`、`string`）。`STRUCT` 表示带命名字段的用户定义记录类型。 |
| `optional` | `boolean` | 若参数在策略签名中声明为可选则为 `true`。 |
| `position` | `number` | 参数在函数签名中的零基索引。 |
| `fields` | `array<FieldSchema>` | 仅当 `typeKind` 为 `"STRUCT"` 时非空。列出 struct 类型的命名字段。`PRIMITIVE` 参数为空数组。 |

### FieldSchema

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `name` | `string` | struct 内的字段名。 |
| `type` | `string` | 字段类型名（自身可能为 `PRIMITIVE` 或另一个 `STRUCT`）。 |
| `typeKind` | `"PRIMITIVE" \| "STRUCT"` | 此字段的类型分类。 |

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 请求已处理。检查 `success` 和 `error` 确认是否有解析失败。 |
| `400 Bad Request` | 请求体格式错误或缺少必需字段。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少 `MEMBER` 角色。 |
| `500 Internal Server Error` | 非预期的引擎故障。 |

## 示例

<CodeGroup>

```bash [curl]
curl -X POST https://policy.aster-lang.dev/api/v1/policies/schema \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: acme-corp" \
  -d '{
    "source": "Module Loan.Approval.\nRule isEligible given applicant has age number, income number, creditScore number:\n  If applicant.creditScore >= 700 and applicant.income >= 50000 return true\n  return false",
    "functionName": "isEligible",
    "locale": "en-US"
  }'
```

```js [JavaScript]
const source = `
Module Loan.Approval.
Rule isEligible given applicant has age number, income number, creditScore number:
  If applicant.creditScore >= 700 and applicant.income >= 50000 return true
  return false
`.trim();

const response = await fetch(
  'https://policy.aster-lang.dev/api/v1/policies/schema',
  {
    method: 'POST',
    headers: {
      Authorization: 'Bearer <token>',
      'Content-Type': 'application/json',
      'X-Tenant-ID': 'acme-corp',
    },
    body: JSON.stringify({
      source,
      functionName: 'isEligible',
      locale: 'en-US',
    }),
  }
);

const data = await response.json();

if (data.success) {
  data.parameters.forEach((param) => {
    console.log(`${param.name}: ${param.type} (${param.typeKind})`);
    param.fields.forEach((f) => console.log(`  .${f.name}: ${f.type}`));
  });
}
```

</CodeGroup>

### 示例响应

```json
{
  "success": true,
  "moduleName": "Loan.Approval",
  "functionName": "isEligible",
  "parameters": [
    {
      "name": "applicant",
      "type": "Applicant",
      "typeKind": "STRUCT",
      "optional": false,
      "position": 0,
      "fields": [
        { "name": "age", "type": "number", "typeKind": "PRIMITIVE" },
        { "name": "income", "type": "number", "typeKind": "PRIMITIVE" },
        { "name": "creditScore", "type": "number", "typeKind": "PRIMITIVE" }
      ]
    }
  ],
  "error": null
}
```

### 示例响应（解析失败）

```json
{
  "success": false,
  "moduleName": null,
  "functionName": null,
  "parameters": [],
  "error": "Parse error at line 2: expected 'given' after function name"
}
```
