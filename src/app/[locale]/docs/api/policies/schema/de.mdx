# Policy-Parameter-Schema extrahieren

Parsen Sie einen CNL-Quellcode-String und geben Sie das Parameter-Schema für die angegebene Funktion zurück. Verwenden Sie diesen Endpunkt, um die Form der Daten zu entdecken, die eine Policy erwartet, bevor Sie Evaluierungsanfragen konstruieren, oder um dynamische Formulargenerierung in Tooling zu steuern.

## Endpunkt

`POST /api/v1/policies/schema`

## Erforderliche Rolle

`MEMBER`

## Header

| Header | Wert | Erforderlich |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | Ja |
| `Content-Type` | `application/json` | Ja |
| `X-Tenant-ID` | Mandanten-Identifikator-String | Ja |

## Request-Body

```json
{
  "source": "string",
  "functionName": "string",
  "locale": "en-US"
}
```

| Feld | Typ | Erforderlich | Beschreibung |
|-------|------|----------|-------------|
| `source` | `string` | Ja | Roher CNL-Policy-Quellcode zum Parsen. Die Engine extrahiert Typdeklarationen aus dem Quellcode, ohne Policy-Logik auszuführen. |
| `functionName` | `string` | Nein | Name der Funktion, deren Parameter-Schema extrahiert werden soll. Wenn weggelassen, extrahiert die Engine das Schema für die erste im Quellcode deklarierte Funktion. |
| `locale` | `string` | Nein | BCP-47-Locale-Tag, das den CNL-Schlüsselwortsatz identifiziert. Standard: `"en-US"`. Verwenden Sie `"zh-CN"` für vereinfachtes Chinesisches CNL-Syntax. |

## Response-Body

```json
{
  "success": true,
  "moduleName": "string",
  "functionName": "string",
  "parameters": [
    {
      "name": "string",
      "type": "string",
      "typeKind": "PRIMITIVE",
      "optional": false,
      "position": 0,
      "fields": []
    }
  ],
  "error": null
}
```

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `success` | `boolean` | `true`, wenn der Quellcode erfolgreich geparst wurde und die Schema-Extraktion ohne Fehler abgeschlossen wurde. |
| `moduleName` | `string` | Der im Quellcode deklarierte Modulname. |
| `functionName` | `string` | Der Funktionsname, dessen Schema extrahiert wurde. Stimmt mit dem `functionName` der Anfrage überein, oder der ersten Funktion, falls keine angegeben wurde. |
| `parameters` | `array<ParameterSchema>` | Geordnete Liste von Parameter-Deskriptoren. Die Reihenfolge entspricht der positionalen Deklarationsreihenfolge im CNL-Quellcode. |
| `error` | `string \| null` | Parsing-Fehlermeldung, wenn `success` `false` ist; `null` bei Erfolg. |

### ParameterSchema

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `name` | `string` | Parametername wie im CNL-Quellcode deklariert. |
| `type` | `string` | Typname wie deklariert (z. B. `"number"`, `"boolean"`, `"string"`, `"Order"`, `"Applicant"`). |
| `typeKind` | `"PRIMITIVE" \| "STRUCT"` | `PRIMITIVE` für eingebaute Skalartypen (`number`, `boolean`, `string`). `STRUCT` für benutzerdefinierte Record-Typen mit benannten Feldern. |
| `optional` | `boolean` | `true`, wenn der Parameter in der Policy-Signatur als optional deklariert ist. |
| `position` | `number` | Nullbasierter Index des Parameters in der Funktionssignatur. |
| `fields` | `array<FieldSchema>` | Nur dann nicht leer, wenn `typeKind` `"STRUCT"` ist. Listet die benannten Felder des Struct-Typs auf. Leeres Array für `PRIMITIVE`-Parameter. |

### FieldSchema

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `name` | `string` | Feldname innerhalb des Structs. |
| `type` | `string` | Feldtypname (kann selbst `PRIMITIVE` oder ein weiteres `STRUCT` sein). |
| `typeKind` | `"PRIMITIVE" \| "STRUCT"` | Typklassifizierung dieses Felds. |

## HTTP-Statuscodes

| Status | Bedeutung |
|--------|---------|
| `200 OK` | Anfrage verarbeitet. Prüfen Sie `success` und `error` auf Parsing-Fehler. |
| `400 Bad Request` | Fehlerhafter Request-Body oder fehlende Pflichtfelder. |
| `401 Unauthorized` | Fehlender oder ungültiger Bearer-Token. |
| `403 Forbidden` | Token ist gültig, dem Aufrufer fehlt jedoch die `MEMBER`-Rolle. |
| `500 Internal Server Error` | Unerwarteter Engine-Fehler. |

## Beispiele

<CodeGroup>

```bash [curl]
curl -X POST https://policy.aster-lang.dev/api/v1/policies/schema \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: acme-corp" \
  -d '{
    "source": "Module Loan.Approval.\nRule isEligible given applicant has age number, income number, creditScore number:\n  If applicant.creditScore >= 700 and applicant.income >= 50000 return true\n  return false",
    "functionName": "isEligible",
    "locale": "en-US"
  }'
```

```js [JavaScript]
const source = `
Module Loan.Approval.
Rule isEligible given applicant has age number, income number, creditScore number:
  If applicant.creditScore >= 700 and applicant.income >= 50000 return true
  return false
`.trim();

const response = await fetch(
  'https://policy.aster-lang.dev/api/v1/policies/schema',
  {
    method: 'POST',
    headers: {
      Authorization: 'Bearer <token>',
      'Content-Type': 'application/json',
      'X-Tenant-ID': 'acme-corp',
    },
    body: JSON.stringify({
      source,
      functionName: 'isEligible',
      locale: 'en-US',
    }),
  }
);

const data = await response.json();

if (data.success) {
  data.parameters.forEach((param) => {
    console.log(`${param.name}: ${param.type} (${param.typeKind})`);
    param.fields.forEach((f) => console.log(`  .${f.name}: ${f.type}`));
  });
}
```

</CodeGroup>

### Beispiel-Antwort

```json
{
  "success": true,
  "moduleName": "Loan.Approval",
  "functionName": "isEligible",
  "parameters": [
    {
      "name": "applicant",
      "type": "Applicant",
      "typeKind": "STRUCT",
      "optional": false,
      "position": 0,
      "fields": [
        { "name": "age", "type": "number", "typeKind": "PRIMITIVE" },
        { "name": "income", "type": "number", "typeKind": "PRIMITIVE" },
        { "name": "creditScore", "type": "number", "typeKind": "PRIMITIVE" }
      ]
    }
  ],
  "error": null
}
```

### Beispiel-Antwort (Parse-Fehler)

```json
{
  "success": false,
  "moduleName": null,
  "functionName": null,
  "parameters": [],
  "error": "Parse error at line 2: expected 'given' after function name"
}
```
