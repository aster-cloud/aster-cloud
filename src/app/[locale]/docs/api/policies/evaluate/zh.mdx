# 评估策略

按模块和函数名评估已部署的策略。策略必须先部署到引擎，才能通过此端点调用。

## 端点

`POST /api/v1/policies/evaluate`

## 必需角色

`MEMBER`

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `Content-Type` | `application/json` | 是 |
| `X-Tenant-ID` | 租户标识符字符串 | 是 |

## 请求体

```json
{
  "policyModule": "string",
  "policyFunction": "string",
  "context": [{}]
}
```

| 字段 | 类型 | 必需 | 描述 |
|-------|------|----------|-------------|
| `policyModule` | `string` | 是 | CNL 源代码中声明的完全限定模块名（如 `"Loan.Approval"`）。 |
| `policyFunction` | `string` | 是 | 要调用的模块内函数名（如 `"isEligible"`）。 |
| `context` | `array<object>` | 是 | 按位置传递给策略函数的参数对象有序列表。每个对象的结构必须与策略中声明的参数 schema 匹配。零参数函数请传入空数组 `[]`。 |

## 响应体

```json
{
  "result": "<any>",
  "executionTimeMs": 0,
  "error": null,
  "decisionTrace": null
}
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `result` | `any` | 策略函数返回的值。类型匹配函数声明的返回类型（boolean、number、string 或 object）。 |
| `executionTimeMs` | `number` | 从接收请求到分发响应的挂钟时间（毫秒）。 |
| `error` | `string \| null` | 评估失败时的人类可读错误消息；成功时为 `null`。 |
| `decisionTrace` | `object \| null` | 规则评估步骤的结构化追踪。此端点始终为 `null`。需要追踪请使用 `/evaluate-source?trace=true`。 |

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 评估完成。检查 `error` 字段 —— 非 null 值表示 HTTP 调用本身成功但策略层面失败。 |
| `400 Bad Request` | 请求体格式错误或缺少必需字段。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少 `MEMBER` 角色。 |
| `404 Not Found` | 未找到与 `policyModule` + `policyFunction` 匹配的已部署策略。 |
| `500 Internal Server Error` | 非预期的引擎故障。 |

## 示例

<CodeGroup>

```bash [curl]
curl -X POST https://policy.aster-lang.dev/api/v1/policies/evaluate \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: acme-corp" \
  -d '{
    "policyModule": "Loan.Approval",
    "policyFunction": "isEligible",
    "context": [
      {
        "applicantAge": 30,
        "annualIncome": 75000,
        "creditScore": 720,
        "requestedAmount": 25000
      }
    ]
  }'
```

```js [JavaScript]
const response = await fetch(
  'https://policy.aster-lang.dev/api/v1/policies/evaluate',
  {
    method: 'POST',
    headers: {
      Authorization: 'Bearer <token>',
      'Content-Type': 'application/json',
      'X-Tenant-ID': 'acme-corp',
    },
    body: JSON.stringify({
      policyModule: 'Loan.Approval',
      policyFunction: 'isEligible',
      context: [
        {
          applicantAge: 30,
          annualIncome: 75000,
          creditScore: 720,
          requestedAmount: 25000,
        },
      ],
    }),
  }
);

const data = await response.json();
// data.result  → true | false | number | string | object
// data.error   → null on success
```

</CodeGroup>

### 示例响应

```json
{
  "result": true,
  "executionTimeMs": 4,
  "error": null,
  "decisionTrace": null
}
```
