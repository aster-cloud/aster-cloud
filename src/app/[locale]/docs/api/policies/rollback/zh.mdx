# 将策略回滚到指定版本

将策略恢复为之前保存的版本。引擎以原子方式切换激活版本，使后续评估请求立即使用目标版本。回滚操作会作为新的版本条目记录在历史中。

## 端点

`POST /api/v1/policies/{policyId}/rollback`

## 必需角色

`MEMBER`

## 路径参数

| 参数 | 类型 | 必需 | 描述 |
|-----------|------|----------|-------------|
| `policyId` | `string` | 是 | 要回滚的策略的内部 UUID。 |

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `Content-Type` | `application/json` | 是 |
| `X-Tenant-ID` | 租户标识符字符串 | 是 |

## 请求体

```json
{
  "targetVersion": 0,
  "reason": "string"
}
```

| 字段 | 类型 | 必需 | 描述 |
|-------|------|----------|-------------|
| `targetVersion` | `number` | 是 | 要恢复的版本号。必须是策略版本历史中存在的正整数。使用 [versions 端点](/zh/docs/api/policies/versions) 枚举可用版本。 |
| `reason` | `string` | 否 | 回滚的人类可读说明。存储在此操作创建的版本历史条目中。对审计追踪很有用。 |

## 响应体

```json
{
  "success": true,
  "previousVersion": 3,
  "currentVersion": 1
}
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `success` | `boolean` | 若回滚完成且策略现在提供目标版本则为 `true`。 |
| `previousVersion` | `number` | 此回滚之前立即激活的版本号。 |
| `currentVersion` | `number` | 回滚后当前激活的版本号。匹配请求中的 `targetVersion`。 |

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 回滚完成。策略现在提供 `targetVersion`。 |
| `400 Bad Request` | 请求体格式错误、缺少 `targetVersion`，或 `targetVersion` 不在版本历史中。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少 `MEMBER` 角色。 |
| `404 Not Found` | 租户内未找到给定 `policyId` 的策略。 |
| `409 Conflict` | 所请求的 `targetVersion` 已是当前激活版本。 |
| `500 Internal Server Error` | 非预期的引擎故障。返回此状态时激活版本不变。 |

## 示例

<CodeGroup>

```bash [curl]
curl -X POST \
  "https://policy.aster-lang.dev/api/v1/policies/d4e5f6a7-b8c9-4d0e-1f2a-3b4c5d6e7f8a/rollback" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: acme-corp" \
  -d '{
    "targetVersion": 1,
    "reason": "Version 3 caused incorrect rejections for applicants with income between 45000-49999. Rolling back pending investigation."
  }'
```

```js [JavaScript]
const policyId = 'd4e5f6a7-b8c9-4d0e-1f2a-3b4c5d6e7f8a';

const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/policies/${policyId}/rollback`,
  {
    method: 'POST',
    headers: {
      Authorization: 'Bearer <token>',
      'Content-Type': 'application/json',
      'X-Tenant-ID': 'acme-corp',
    },
    body: JSON.stringify({
      targetVersion: 1,
      reason:
        'Version 3 caused incorrect rejections for applicants with income between 45000-49999. Rolling back pending investigation.',
    }),
  }
);

const data = await response.json();

if (data.success) {
  console.log(
    `Rolled back from v${data.previousVersion} to v${data.currentVersion}`
  );
} else {
  console.error('Rollback failed');
}
```

</CodeGroup>

### 示例响应

```json
{
  "success": true,
  "previousVersion": 3,
  "currentVersion": 1
}
```

### 示例响应（目标版本已激活）

HTTP `409 Conflict`：

```json
{
  "success": false,
  "error": "Version 3 is already the active version for policy 'd4e5f6a7-b8c9-4d0e-1f2a-3b4c5d6e7f8a'"
}
```
