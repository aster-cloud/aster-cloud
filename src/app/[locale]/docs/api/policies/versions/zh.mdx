# 获取策略版本历史

获取由内部策略 ID 标识的策略的完整版本历史。响应中的每个条目代表一个已保存的独立版本，包括当前激活的版本。

## 端点

`GET /api/v1/policies/{policyId}/versions`

## 必需角色

`MEMBER`

## 路径参数

| 参数 | 类型 | 必需 | 描述 |
|-----------|------|----------|-------------|
| `policyId` | `string` | 是 | 策略资源的内部 UUID。从策略管理 API 或 Aster 仪表板获取此值。 |

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `X-Tenant-ID` | 租户标识符字符串 | 是 |

## 请求体

无。

## 响应体

按版本号升序排列的版本对象数组。

```json
[
  {
    "version": 1,
    "active": false,
    "moduleName": "string",
    "functionName": "string",
    "createdAt": "ISO8601",
    "createdBy": "string",
    "notes": "string"
  }
]
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `version` | `number` | 单调递增的整数版本号。版本 `1` 为初始部署。 |
| `active` | `boolean` | 数组中恰好有一个条目为 `true` —— 即当前处理评估请求的版本。 |
| `moduleName` | `string` | 此版本策略源代码中声明的 CNL 模块名。 |
| `functionName` | `string` | 此版本策略的主函数名。 |
| `createdAt` | `string` | 记录此版本保存时间的 ISO 8601 时间戳（如 `"2024-03-15T09:30:00Z"`）。 |
| `createdBy` | `string` | 创建此版本的主体的标识符（邮箱或用户 ID）。 |
| `notes` | `string` | 创建版本时附带的可选人类可读部署备注。未提供备注则为空字符串。 |

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 返回版本历史。空数组表示策略存在但无版本记录。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少 `MEMBER` 角色。 |
| `404 Not Found` | 租户内未找到给定 `policyId` 的策略。 |
| `500 Internal Server Error` | 非预期的引擎故障。 |

## 示例

<CodeGroup>

```bash [curl]
curl -X GET \
  "https://policy.aster-lang.dev/api/v1/policies/d4e5f6a7-b8c9-4d0e-1f2a-3b4c5d6e7f8a/versions" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const policyId = 'd4e5f6a7-b8c9-4d0e-1f2a-3b4c5d6e7f8a';

const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/policies/${policyId}/versions`,
  {
    method: 'GET',
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const versions = await response.json();

const active = versions.find((v) => v.active);
console.log(`Active version: ${active?.version}`);

versions.forEach((v) => {
  const marker = v.active ? ' [ACTIVE]' : '';
  console.log(`v${v.version}${marker} — ${v.createdAt} by ${v.createdBy}`);
});
```

</CodeGroup>
