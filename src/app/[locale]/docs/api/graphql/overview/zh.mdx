# GraphQL API 概览

Aster 策略引擎暴露 GraphQL API 用于查询和管理策略。它基于 **SmallRye GraphQL**（MicroProfile GraphQL 实现）构建，提供 MicroProfile GraphQL 的全部特性，包括内置内省、类型安全和托管的 schema 端点。

## 端点

| 用途 | URL |
|---------|-----|
| Query / Mutation 执行 | `POST /graphql` |
| Schema (SDL) | `GET /api/graphql/schema.graphql` |

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `Content-Type` | `application/json` | 是 |
| `X-Tenant-Id` | 租户标识符字符串 | 是 |
| `Idempotency-Key` | 客户端生成的唯一字符串（推荐 UUID） | 仅 Mutation |

<Callout type="tip" title="Idempotency-Key">
在 Mutation 请求上提供 `Idempotency-Key` 可确保重试失败或超时的请求不会再次执行该操作。服务器以此值为键缓存 Mutation 结果 24 小时。该请求头是可选的，但强烈推荐用于写操作。
</Callout>

## 请求格式

所有请求必须为 HTTP `POST`，请求体为符合 GraphQL over HTTP 规范的 JSON：

```json
{
  "query": "query { ... }",
  "variables": {},
  "operationName": "OptionalOperationName"
}
```

| 字段 | 类型 | 必需 | 描述 |
|-------|------|----------|-------------|
| `query` | `string` | 是 | 包含要执行操作的 GraphQL 文档。 |
| `variables` | `object` | 否 | `query` 中引用的命名变量值。 |
| `operationName` | `string` | 否 | 当 `query` 包含多个命名操作时，用于消除歧义指定执行哪个。 |

## 响应格式

```json
{
  "data": {},
  "errors": []
}
```

所有格式良好的 GraphQL 响应都会返回 `200 OK` HTTP 状态，包括部分成功的情况。务必检查 `errors` 数组 —— 非空值表示一个或多个字段解析器发生错误，即使 `data` 已部分填充。

## Schema

下载 SDL 格式的完整 schema：

<CodeGroup>

```bash [curl]
curl -X GET https://policy.aster-lang.dev/api/graphql/schema.graphql \
  -H "Authorization: Bearer <token>"
```

</CodeGroup>

## 错误处理

GraphQL 错误遵循 [GraphQL 规范的错误格式](https://spec.graphql.org/October2021/#sec-Errors)：

```json
{
  "data": null,
  "errors": [
    {
      "message": "Policy not found",
      "locations": [{ "line": 2, "column": 3 }],
      "path": ["getPolicy"],
      "extensions": {
        "code": "NOT_FOUND",
        "classification": "DataFetchingException"
      }
    }
  ]
}
```

| Extension 字段 | 描述 |
|-----------------|-------------|
| `code` | 机器可读的错误码（如 `NOT_FOUND`、`FORBIDDEN`、`VALIDATION_ERROR`）。 |
| `classification` | SmallRye GraphQL 错误分类。 |

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 返回 GraphQL 响应（检查 `errors` 字段确认是否有部分失败）。 |
| `400 Bad Request` | 请求体不是有效的 JSON，或 GraphQL 文档存在语法错误。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少所请求操作的角色权限。 |
| `500 Internal Server Error` | GraphQL 层响应之前发生的非预期引擎故障。 |
