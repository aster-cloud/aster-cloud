# GraphQL-Abfragen

Alle Abfragen sind schreibgeschützte Operationen, die als `POST /graphql` gesendet werden. Abfragen erfordern HMAC-Anfragensignierung und einen `X-Tenant-Id`-Header. Details zur Berechnung der Signatur siehe [Authentifizierung](/de/docs/getting-started/authentication); Details zum Anfrageformat siehe [Überblick](/de/docs/api/graphql/overview).

---

## Policy-Abfragen

### getPolicy

Eine einzelne Policy anhand ihres eindeutigen Bezeichners abrufen.

```graphql
query GetPolicy($id: ID!) {
  getPolicy(id: $id) {
    id
    policyModule
    policyFunction
    version
    status
    createdAt
    updatedAt
    source
  }
}
```

**Variablen**

```json
{
  "id": "pol-abc123"
}
```

<CodeGroup>

```bash [curl]
curl -X POST https://policy.aster-lang.dev/graphql \
  -H "Content-Type: application/json" \
  -H "X-Tenant-Id: acme-corp" \
  -H "X-User-Role: VIEWER" \
  -H "X-Aster-Signature: <signature>" \
  -H "X-Aster-Nonce: <nonce>" \
  -H "X-Aster-Timestamp: <timestamp>" \
  -d '{
    "query": "query GetPolicy($id: ID!) { getPolicy(id: $id) { id policyModule policyFunction version status createdAt updatedAt } }",
    "variables": { "id": "pol-abc123" }
  }'
```

```js [JavaScript]
const response = await fetch('https://policy.aster-lang.dev/graphql', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-Tenant-Id':  'acme-corp',
    'X-User-Role':  'VIEWER',
    'X-Aster-Signature': signature,
    'X-Aster-Nonce': nonce,
    'X-Aster-Timestamp': timestamp,
  },
  body: JSON.stringify({
    query: `
      query GetPolicy($id: ID!) {
        getPolicy(id: $id) {
          id
          policyModule
          policyFunction
          version
          status
          createdAt
          updatedAt
        }
      }
    `,
    variables: { id: 'pol-abc123' },
  }),
});

const { data, errors } = await response.json();
```

</CodeGroup>

### listPolicies

Alle für den Mandanten sichtbaren Policies abrufen.

```graphql
query ListPolicies {
  listPolicies {
    id
    policyModule
    policyFunction
    version
    status
    updatedAt
  }
}
```

<CodeGroup>

## Branchen-spezifische Abfragen

Diese Abfragen rufen domänenspezifische Policy-Evaluierungslogik auf und liefern strukturierte Entscheidungsergebnisse. Jede Abfrage übergibt ihre Argumente als **einzelne Parameter** (nicht als ein einzelnes Eingabeobjekt) an die Policy-Engine.

### generateLifeQuote

Lebensversicherungs-Angebot basierend auf den Antragsteller-Parametern erzeugen.

```graphql
query GenerateLifeQuote(
  $applicant: LifeInsuranceApplicant!
  $request: LifeInsurancePolicyRequest!
) {
  generateLifeQuote(applicant: $applicant, request: $request) {
    premium
    coverageAmount
    term
    eligibility
    exclusions
  }
}
```

---

### calculateLifeRiskScore

Risiko-Score für einen Lebensversicherungs-Antragsteller berechnen.

```graphql
query CalculateLifeRiskScore($applicant: LifeInsuranceApplicant!) {
  calculateLifeRiskScore(applicant: $applicant) {
    score
    band
    factors
  }
}
```

---

### generateAutoQuote

KFZ-Versicherungs-Angebot erzeugen.

```graphql
query GenerateAutoQuote(
  $driver: AutoInsuranceDriver!
  $vehicle: AutoInsuranceVehicle!
  $coverageType: String!
) {
  generateAutoQuote(
    driver: $driver
    vehicle: $vehicle
    coverageType: $coverageType
  ) {
    annualPremium
    monthlyPremium
    coverageOptions {
      type
      included
      premium
    }
  }
}
```

---

### checkServiceEligibility

Bestimmen, ob ein Patient für eine bestimmte Leistung berechtigt ist.

```graphql
query CheckServiceEligibility(
  $patient: HealthcarePatient!
  $service: HealthcareService!
) {
  checkServiceEligibility(patient: $patient, service: $service) {
    eligible
    reason
    eligibleServices
    ineligibleServices {
      service
      reason
    }
  }
}
```

---

### processClaim

Versicherungs- oder Leistungsanspruch evaluieren und verarbeiten.

```graphql
query ProcessClaim(
  $claim: HealthcareClaim!
  $provider: HealthcareProvider!
  $patientCoverage: Int!
) {
  processClaim(
    claim: $claim
    provider: $provider
    patientCoverage: $patientCoverage
  ) {
    approved
    approvedAmount
    denialReason
    requiredDocuments
    referenceNumber
  }
}
```

    conditions
