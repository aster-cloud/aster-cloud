# Versionsvergleich

Vergleichen Sie die Performance-Metriken zweier Policy-Versionen Seite an Seite über ein gemeinsames Beobachtungsfenster. Dies ist nützlich, um zu validieren, dass eine neu bereitgestellte Version mindestens so gut abschneidet wie ihre Vorgängerin, bevor sie vollständig ausgerollt wird.

## Endpunkt

`GET /api/v1/audit/compare`

## Erforderliche Rolle

`ADMIN`

## Header

| Header | Wert | Erforderlich |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | Ja |
| `X-Tenant-ID` | Mandanten-Identifikator-String | Ja |

## Query-Parameter

| Parameter | Typ | Erforderlich | Beschreibung |
|-----------|------|----------|-------------|
| `versionA` | `string` | Ja | Bezeichner der ersten Policy-Version (typischerweise Baseline oder aktuelle Version). |
| `versionB` | `string` | Ja | Bezeichner der zweiten Policy-Version (typischerweise Kandidaten- oder neuere Version). |
| `days` | `integer` | Nein | Anzahl der Tage Historie, die verglichen werden sollen. Standard: `30`. Maximum: `90`. |

<Callout type="warning" title="Limit für Zeitfenster">
`days` darf **90** nicht überschreiten. Anfragen mit einem größeren Wert werden mit `400 Bad Request` abgelehnt.
</Callout>

## Response-Body

```json
{
  "versionA": "v-abc123",
  "versionB": "v-def456",
  "windowDays": 30,
  "metrics": {
    "versionA": {
      "totalEvaluations": 18420,
      "avgExecutionTimeMs": 7.2,
      "p95ExecutionTimeMs": 18.1,
      "p99ExecutionTimeMs": 42.3,
      "failureRate": 0.008,
      "errorCount": 147
    },
    "versionB": {
      "totalEvaluations": 4310,
      "avgExecutionTimeMs": 6.8,
      "p95ExecutionTimeMs": 16.4,
      "p99ExecutionTimeMs": 38.9,
      "failureRate": 0.003,
      "errorCount": 13
    }
  },
  "comparison": {
    "avgExecutionTimeDeltaMs": -0.4,
    "avgExecutionTimeDeltaPct": -5.6,
    "failureRateDelta": -0.005,
    "failureRateDeltaPct": -62.5,
    "verdict": "VERSION_B_BETTER"
  }
}
```

### Metrik-Felder

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `totalEvaluations` | `number` | Gesamtzahl der für diese Version im Fenster aufgezeichneten Policy-Evaluierungen. |
| `avgExecutionTimeMs` | `number` | Mittlere Wanduhr-Ausführungszeit in Millisekunden. |
| `p95ExecutionTimeMs` | `number` | 95.-Perzentil-Ausführungszeit in Millisekunden. |
| `p99ExecutionTimeMs` | `number` | 99.-Perzentil-Ausführungszeit in Millisekunden. |
| `failureRate` | `number` | Anteil der Evaluierungen, die einen Fehler ergaben (0.0 bis 1.0). |
| `errorCount` | `number` | Absolute Anzahl fehlgeschlagener Evaluierungen. |

### Vergleichsfelder

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `avgExecutionTimeDeltaMs` | `number` | Differenz der durchschnittlichen Ausführungszeit: `versionB.avg − versionA.avg`. Negativ bedeutet, versionB ist schneller. |
| `avgExecutionTimeDeltaPct` | `number` | Dieselbe Differenz als Prozentsatz des Durchschnitts von versionA. |
| `failureRateDelta` | `number` | Differenz der Fehlerrate: `versionB.failureRate − versionA.failureRate`. Negativ bedeutet, versionB ist zuverlässiger. |
| `failureRateDeltaPct` | `number` | Dieselbe Differenz als Prozentsatz der Fehlerrate von versionA. |
| `verdict` | `string` | Zusammenfassendes Urteil: `VERSION_A_BETTER`, `VERSION_B_BETTER` oder `COMPARABLE`. |

## HTTP-Statuscodes

| Status | Bedeutung |
|--------|---------|
| `200 OK` | Vergleich erfolgreich abgeschlossen. |
| `400 Bad Request` | Fehlende Pflicht-Parameter, identische Versions-Bezeichner oder `days` überschreitet das 90-Tage-Limit. |
| `401 Unauthorized` | Fehlender oder ungültiger Bearer-Token. |
| `403 Forbidden` | Token ist gültig, dem Aufrufer fehlt jedoch die `ADMIN`-Rolle. |
| `404 Not Found` | Einer oder beide Versions-Bezeichner existieren nicht. |
| `500 Internal Server Error` | Unerwarteter Engine-Fehler. |

## Beispiele

<CodeGroup>

```bash [curl]
curl -X GET "https://policy.aster-lang.dev/api/v1/audit/compare?versionA=v-abc123&versionB=v-def456&days=30" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const params = new URLSearchParams({
  versionA: 'v-abc123',
  versionB: 'v-def456',
  days:     '30',
});

const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/audit/compare?${params}`,
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const comparison = await response.json();

if (comparison.comparison.verdict === 'VERSION_B_BETTER') {
  console.log('New version outperforms the baseline — safe to promote.');
}
```

</CodeGroup>
