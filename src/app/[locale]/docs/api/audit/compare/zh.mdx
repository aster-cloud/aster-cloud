# 版本比较

在共享观察窗口内并排比较两个策略版本的性能指标。这有助于在全面发布之前验证新部署的版本至少与其前任表现相当。

## 端点

`GET /api/v1/audit/compare`

## 必需角色

`ADMIN`

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `X-Tenant-ID` | 租户标识符字符串 | 是 |

## 查询参数

| 参数 | 类型 | 必需 | 描述 |
|-----------|------|----------|-------------|
| `versionA` | `string` | 是 | 第一个策略版本的标识符（通常是基线或当前版本）。 |
| `versionB` | `string` | 是 | 第二个策略版本的标识符（通常是候选或较新版本）。 |
| `days` | `integer` | 否 | 比较的历史天数。默认为 `30`。最大值：`90`。 |

<Callout type="warning" title="时间窗口限制">
`days` 不得超过 **90**。超过此值的请求将返回 `400 Bad Request`。
</Callout>

## 响应体

```json
{
  "versionA": "v-abc123",
  "versionB": "v-def456",
  "windowDays": 30,
  "metrics": {
    "versionA": {
      "totalEvaluations": 18420,
      "avgExecutionTimeMs": 7.2,
      "p95ExecutionTimeMs": 18.1,
      "p99ExecutionTimeMs": 42.3,
      "failureRate": 0.008,
      "errorCount": 147
    },
    "versionB": {
      "totalEvaluations": 4310,
      "avgExecutionTimeMs": 6.8,
      "p95ExecutionTimeMs": 16.4,
      "p99ExecutionTimeMs": 38.9,
      "failureRate": 0.003,
      "errorCount": 13
    }
  },
  "comparison": {
    "avgExecutionTimeDeltaMs": -0.4,
    "avgExecutionTimeDeltaPct": -5.6,
    "failureRateDelta": -0.005,
    "failureRateDeltaPct": -62.5,
    "verdict": "VERSION_B_BETTER"
  }
}
```

### 指标字段

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `totalEvaluations` | `number` | 窗口内该版本记录的策略评估总次数。 |
| `avgExecutionTimeMs` | `number` | 平均挂钟执行时间（毫秒）。 |
| `p95ExecutionTimeMs` | `number` | 95 百分位执行时间（毫秒）。 |
| `p99ExecutionTimeMs` | `number` | 99 百分位执行时间（毫秒）。 |
| `failureRate` | `number` | 评估失败的比率（0.0 到 1.0）。 |
| `errorCount` | `number` | 失败评估的绝对数量。 |

### 比较字段

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `avgExecutionTimeDeltaMs` | `number` | 平均执行时间差：`versionB.avg − versionA.avg`。负值表示 versionB 更快。 |
| `avgExecutionTimeDeltaPct` | `number` | 同一差值以 versionA 平均值的百分比表示。 |
| `failureRateDelta` | `number` | 失败率差：`versionB.failureRate − versionA.failureRate`。负值表示 versionB 更可靠。 |
| `failureRateDeltaPct` | `number` | 同一差值以 versionA 失败率的百分比表示。 |
| `verdict` | `string` | 总结判断：`VERSION_A_BETTER`、`VERSION_B_BETTER` 或 `COMPARABLE`。 |

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 比较成功完成。 |
| `400 Bad Request` | 缺少必需参数、版本标识符相同，或 `days` 超过 90 天上限。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少 `ADMIN` 角色。 |
| `404 Not Found` | 一个或两个版本标识符不存在。 |
| `500 Internal Server Error` | 非预期的引擎故障。 |

## 示例

<CodeGroup>

```bash [curl]
curl -X GET "https://policy.aster-lang.dev/api/v1/audit/compare?versionA=v-abc123&versionB=v-def456&days=30" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const params = new URLSearchParams({
  versionA: 'v-abc123',
  versionB: 'v-def456',
  days:     '30',
});

const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/audit/compare?${params}`,
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const comparison = await response.json();

if (comparison.comparison.verdict === 'VERSION_B_BETTER') {
  console.log('New version outperforms the baseline — safe to promote.');
}
```

</CodeGroup>
