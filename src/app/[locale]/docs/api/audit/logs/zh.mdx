# 审计日志

<Callout type="tip" title="范围">
这些端点由 **aster-api**（策略引擎）提供，覆盖了经 SHA-256 哈希链处理的策略执行事件。**aster-cloud** SaaS 仪表板维护一个独立的、非链式的活动日志用于 UI 事件（用户登录、套餐变更、成员邀请）；该活动日志不通过此 API 暴露。
</Callout>

获取由策略引擎记录的事件的审计日志条目。本节中的所有端点都需要 `ADMIN` 角色。

## 必需角色

`ADMIN`

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `X-Tenant-ID` | 租户标识符字符串 | 是 |

---

## 获取所有审计日志

获取租户所有审计日志条目的列表，按事件时间降序排列。

### 端点

`GET /api/v1/audit`

### 响应体

```json
[
  {
    "id": "string",
    "eventType": "string",
    "policyModule": "string",
    "policyFunction": "string",
    "actorId": "string",
    "occurredAt": "2024-01-15T10:30:00Z",
    "payload": {},
    "hash": "string",
    "previousHash": "string"
  }
]
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `id` | `string` | 唯一的审计记录标识符。 |
| `eventType` | `string` | 被记录的事件类型（如 `POLICY_EVALUATED`、`POLICY_DEPLOYED`）。 |
| `policyModule` | `string` | 与事件相关的模块名（若适用）。 |
| `policyFunction` | `string` | 与事件相关的函数名（若适用）。 |
| `actorId` | `string` | 触发事件的用户或服务主体的标识符。 |
| `occurredAt` | `string` | 事件发生时的 ISO 8601 时间戳。 |
| `payload` | `object` | 事件特定的元数据。结构因 `eventType` 而异。 |
| `hash` | `string` | 此记录内容的 SHA-256 哈希，用于链完整性验证。 |
| `previousHash` | `string` | 紧邻的前一条审计记录的哈希，构成哈希链。 |

### 示例

<CodeGroup>

```bash [curl]
curl -X GET https://policy.aster-lang.dev/api/v1/audit \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const response = await fetch(
  'https://policy.aster-lang.dev/api/v1/audit',
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const logs = await response.json();
```

</CodeGroup>

## 按事件类型筛选

获取筛选到特定事件类型的审计日志条目。

### 端点

`GET /api/v1/audit/type/{eventType}`

### 路径参数

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `eventType` | `string` | 要筛选的事件类型（如 `POLICY_EVALUATED`、`POLICY_DEPLOYED`、`POLICY_ROLLED_BACK`）。 |

### 示例

<CodeGroup>

```bash [curl]
curl -X GET https://policy.aster-lang.dev/api/v1/audit/type/POLICY_DEPLOYED \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const eventType = 'POLICY_DEPLOYED';
const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/audit/type/${eventType}`,
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const logs = await response.json();
```

</CodeGroup>

## 按策略筛选

获取特定策略模块和函数组合的审计日志条目。

### 端点

`GET /api/v1/audit/policy/{policyModule}/{policyFunction}`

### 路径参数

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `policyModule` | `string` | 完全限定的模块名（如 `Loan.Approval`）。 |
| `policyFunction` | `string` | 模块内的函数名（如 `isEligible`）。 |

### 示例

<CodeGroup>

```bash [curl]
curl -X GET "https://policy.aster-lang.dev/api/v1/audit/policy/Loan.Approval/isEligible" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const policyModule = 'Loan.Approval';
const policyFunction = 'isEligible';
const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/audit/policy/${policyModule}/${policyFunction}`,
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const logs = await response.json();
```

</CodeGroup>

## 按时间范围筛选

获取特定时间窗口内的审计日志条目。

### 端点

`GET /api/v1/audit/range`

### 查询参数

| 参数 | 类型 | 必需 | 描述 |
|-----------|------|----------|-------------|
| `startTime` | `string` | 是 | ISO 8601 起始时间戳（包含）。 |
| `endTime` | `string` | 是 | ISO 8601 结束时间戳（包含）。 |

### 示例

<CodeGroup>

```bash [curl]
curl -X GET "https://policy.aster-lang.dev/api/v1/audit/range?startTime=2024-01-01T00:00:00Z&endTime=2024-01-31T23:59:59Z" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const params = new URLSearchParams({
  startTime: '2024-01-01T00:00:00Z',
  endTime:   '2024-01-31T23:59:59Z',
});

const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/audit/range?${params}`,
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const logs = await response.json();
```

</CodeGroup>

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 请求成功。返回审计日志条目数组（可能为空）。 |
| `400 Bad Request` | 缺少或格式错误的查询参数。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少 `ADMIN` 角色。 |
| `500 Internal Server Error` | 非预期的引擎故障。 |
