# 版本使用审计

检查特定策略版本在生产中的使用情况：哪些工作流调用了它、评估发生的时间、回滚的影响以及随时间累积的使用统计。

## 必需角色

`ADMIN`

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `X-Tenant-ID` | 租户标识符字符串 | 是 |

---

## 工作流使用

获取使用了特定策略版本的工作流调用的分页列表。

### 端点

`GET /api/v1/audit/policy-versions/{versionId}/usage`

### 路径参数

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `versionId` | `string` | 策略版本标识符。 |

### 查询参数

| 参数 | 类型 | 必需 | 描述 |
|-----------|------|----------|-------------|
| `status` | `string` | 否 | 按状态筛选工作流。`READY`、`RUNNING`、`COMPLETED`、`FAILED`、`COMPENSATING`、`COMPENSATED`、`COMPENSATION_FAILED` 之一。 |
| `page` | `integer` | 否 | 零基页索引。默认为 `0`。 |
| `size` | `integer` | 否 | 每页记录数。默认为 `20`。 |

### 响应体

```json
{
  "content": [
    {
      "workflowId": "string",
      "status": "COMPLETED",
      "policyModule": "string",
      "policyFunction": "string",
      "invokedAt": "2024-01-15T10:30:00Z"
    }
  ],
  "totalElements": 1024,
  "totalPages": 52,
  "page": 0,
  "size": 20
}
```

### 示例

<CodeGroup>

```bash [curl]
curl -X GET "https://policy.aster-lang.dev/api/v1/audit/policy-versions/v-abc123/usage?status=COMPLETED&page=0&size=20" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const versionId = 'v-abc123';
const params = new URLSearchParams({
  status: 'COMPLETED',
  page: '0',
  size: '20',
});

const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/audit/policy-versions/${versionId}/usage?${params}`,
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const data = await response.json();
// data.content → array of workflow usage records
// data.totalElements → total count across all pages
```

</CodeGroup>

## 使用时间线

获取使用特定策略版本进行的评估的按时间排序的分页历史。

### 端点

`GET /api/v1/audit/policy-versions/{versionId}/timeline`

### 路径参数

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `versionId` | `string` | 策略版本标识符。 |

### 查询参数

| 参数 | 类型 | 必需 | 描述 |
|-----------|------|----------|-------------|
| `from` | `string` | 否 | ISO 8601 起始时间戳。默认为 30 天前。 |
| `to` | `string` | 否 | ISO 8601 结束时间戳。默认为当前。 |
| `page` | `integer` | 否 | 零基页索引。默认为 `0`。 |
| `size` | `integer` | 否 | 每页记录数。默认为 `20`。 |

### 响应体

```json
{
  "content": [
    {
      "occurredAt": "2024-01-15T10:30:00Z",
      "workflowId": "string",
      "result": {},
      "executionTimeMs": 12
    }
  ],
  "totalElements": 840,
  "totalPages": 42,
  "page": 0,
  "size": 20
}
```

### 示例

<CodeGroup>

```bash [curl]
curl -X GET "https://policy.aster-lang.dev/api/v1/audit/policy-versions/v-abc123/timeline?from=2024-01-01T00:00:00Z&to=2024-01-31T23:59:59Z&page=0&size=20" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const versionId = 'v-abc123';
const params = new URLSearchParams({
  from: '2024-01-01T00:00:00Z',
  to:   '2024-01-31T23:59:59Z',
  page: '0',
  size: '20',
});

const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/audit/policy-versions/${versionId}/timeline?${params}`,
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const data = await response.json();
```

</CodeGroup>

## 回滚影响评估

评估回滚特定策略版本的影响。响应会列出将受影响的活动工作流数量，以及这些工作流当前所处的状态。

### 端点

`GET /api/v1/audit/policy-versions/{versionId}/impact`

### 路径参数

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `versionId` | `string` | 要评估的策略版本标识符。 |

### 响应体

```json
{
  "versionId": "v-abc123",
  "affectedWorkflows": 37,
  "byStatus": {
    "RUNNING": 12,
    "COMPENSATING": 3,
    "COMPLETED": 22
  },
  "estimatedRisk": "MEDIUM"
}
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `versionId` | `string` | 被评估的版本。 |
| `affectedWorkflows` | `number` | 调用过此版本的工作流总数。 |
| `byStatus` | `object` | 按当前状态对受影响工作流的细分。 |
| `estimatedRisk` | `string` | 回滚风险等级：`LOW`、`MEDIUM` 或 `HIGH`。从非终态工作流的比例派生。 |

### 示例

<CodeGroup>

```bash [curl]
curl -X GET "https://policy.aster-lang.dev/api/v1/audit/policy-versions/v-abc123/impact" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const versionId = 'v-abc123';
const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/audit/policy-versions/${versionId}/impact`,
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const impact = await response.json();
console.log(`Risk level: ${impact.estimatedRisk}`);
console.log(`Active workflows affected: ${impact.byStatus.RUNNING ?? 0}`);
```

</CodeGroup>

## 聚合使用统计

获取策略版本的按时间桶分组的使用统计，适合绘制随时间变化的趋势图。

### 端点

`GET /api/v1/audit/stats/version-usage`

### 查询参数

| 参数 | 类型 | 必需 | 描述 |
|-----------|------|----------|-------------|
| `versionId` | `string` | 是 | 策略版本标识符。 |
| `granularity` | `string` | 是 | 时间桶大小。`hour`、`day`、`week`、`month` 之一。 |
| `from` | `string` | 否 | ISO 8601 起始时间戳。默认为 30 天前。 |
| `to` | `string` | 否 | ISO 8601 结束时间戳。默认为当前。 |

<Callout type="warning" title="时间窗口限制">
所请求的窗口（`to` 减 `from`）不得超过 **90 天**。超过此时长的请求将返回 `400 Bad Request`。
</Callout>

### 响应体

```json
{
  "versionId": "v-abc123",
  "granularity": "day",
  "from": "2024-01-01T00:00:00Z",
  "to": "2024-01-31T23:59:59Z",
  "buckets": [
    {
      "timestamp": "2024-01-01T00:00:00Z",
      "count": 342,
      "avgExecutionTimeMs": 8.4,
      "failureRate": 0.012
    }
  ]
}
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `buckets[].timestamp` | `string` | 时间桶的起始（ISO 8601）。 |
| `buckets[].count` | `number` | 桶内评估的数量。 |
| `buckets[].avgExecutionTimeMs` | `number` | 平均策略执行时间（毫秒）。 |
| `buckets[].failureRate` | `number` | 评估失败的比率（0.0 到 1.0）。 |

### 示例

<CodeGroup>

```bash [curl]
curl -X GET "https://policy.aster-lang.dev/api/v1/audit/stats/version-usage?versionId=v-abc123&granularity=day&from=2024-01-01T00:00:00Z&to=2024-01-31T23:59:59Z" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const params = new URLSearchParams({
  versionId:   'v-abc123',
  granularity: 'day',
  from:        '2024-01-01T00:00:00Z',
  to:          '2024-01-31T23:59:59Z',
});

const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/audit/stats/version-usage?${params}`,
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const stats = await response.json();
// stats.buckets → time-series array for charting
```

</CodeGroup>

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 请求成功。 |
| `400 Bad Request` | 缺少必需参数、时间戳格式错误，或窗口超出限制。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少 `ADMIN` 角色。 |
| `404 Not Found` | 未找到与 `versionId` 匹配的策略版本。 |
| `500 Internal Server Error` | 非预期的引擎故障。 |
