# 哈希链验证

验证指定时间窗口内审计日志哈希链的完整性。审计日志以哈希链结构存储 —— 每条记录都包含前一条记录的哈希 —— 使其防篡改。此端点遍历链并报告每个链节是否有效。

## 端点

`GET /api/v1/audit/verify-chain`

## 必需角色

`ADMIN`

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `X-Tenant-ID` | 租户标识符字符串 | 是 |

## 查询参数

| 参数 | 类型 | 必需 | 描述 |
|-----------|------|----------|-------------|
| `start` | `string` | 是 | ISO 8601 起始时间戳（包含）。 |
| `end` | `string` | 是 | ISO 8601 结束时间戳（包含）。 |

<Callout type="warning" title="时间窗口限制">
所请求的窗口（`end` 减 `start`）不得超过 **30 天**。超过此时长的请求将返回 `400 Bad Request`。
</Callout>

## 响应体

```json
{
  "valid": true,
  "brokenAt": null,
  "reason": null,
  "recordsVerified": 4821
}
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `valid` | `boolean` | 若窗口内每条记录构成完整无断的哈希链则为 `true`；任何一节无效或缺失则为 `false`。 |
| `brokenAt` | `string \| null` | 链断裂的首个记录的 ISO 8601 时间戳。当 `valid` 为 `true` 时为 `null`。 |
| `reason` | `string \| null` | 人类可读的断链原因。当 `valid` 为 `true` 时为 `null`。 |
| `recordsVerified` | `number` | 验证过程中检查的审计记录总数。 |

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 验证完成。检查 `valid` 字段判断链的完整性。 |
| `400 Bad Request` | 参数缺失、时间戳格式错误，或所请求窗口超过 30 天上限。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少 `ADMIN` 角色。 |
| `500 Internal Server Error` | 验证过程中发生的非预期引擎故障。 |

## 示例

<CodeGroup>

```bash [curl]
curl -X GET "https://policy.aster-lang.dev/api/v1/audit/verify-chain?start=2024-01-01T00:00:00Z&end=2024-01-31T23:59:59Z" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const params = new URLSearchParams({
  start: '2024-01-01T00:00:00Z',
  end:   '2024-01-31T23:59:59Z',
});

const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/audit/verify-chain?${params}`,
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const result = await response.json();

if (!result.valid) {
  console.error(`Chain broken at ${result.brokenAt}: ${result.reason}`);
}
```

</CodeGroup>

### 示例响应 — 有效链

```json
{
  "valid": true,
  "brokenAt": null,
  "reason": null,
  "recordsVerified": 4821
}
```

### 示例响应 — 断链

```json
{
  "valid": false,
  "brokenAt": "2024-01-14T08:22:11Z",
  "reason": "Hash mismatch: stored hash does not match recomputed hash for record id=a3f9c1d2",
  "recordsVerified": 512
}
```
