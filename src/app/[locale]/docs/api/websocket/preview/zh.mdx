# WebSocket 预览端点

预览 WebSocket 端点允许开发者实时评估 CNL 策略源代码，而无需将其部署到引擎。它面向交互式工具（如编辑器、演练场和 CI 预览任务）。连接在硬编码的 `preview` 租户下运行，无需认证。

<Callout type="warning" title="预览租户">
此端点上的所有评估都在内建的 `preview` 租户下执行。结果与生产租户数据和已部署的策略隔离。请勿在生产工作流中使用此端点。
</Callout>

## 端点

`ws://<host>/ws/preview`

TLS 加密部署请使用 `wss://`。

## 认证

此端点**不**需要认证。WebSocket 握手在没有任何 token 或 HMAC 请求头的情况下完成。所有请求在固定的 `preview` 租户上下文下执行。

<Callout type="tip">
由于预览端点绕过了标准的 HMAC 签名和 RBAC 执行，它应仅在开发或内部网络边界后暴露。它不适合生产使用。
</Callout>

## 协议

会话在单一持久连接上遵循简单的请求-响应模型。握手完成后，服务器立即发送 `connected` 状态消息。客户端随后发送评估请求；服务器对每个请求单独响应。

### 客户端消息

```json
{
  "policyModule": "Loan.Approval",
  "policyFunction": "isEligible",
  "context": [
    {
      "applicantAge": 30,
      "annualIncome": 75000,
      "creditScore": 720,
      "requestedAmount": 25000
    }
  ]
}
```

| 字段 | 类型 | 必需 | 描述 |
|-------|------|----------|-------------|
| `policyModule` | `string` | 是 | CNL 源代码中声明的完全限定模块名（如 `Loan.Approval`）。 |
| `policyFunction` | `string` | 是 | 要调用的模块内函数。 |
| `context` | `array<object>` | 是 | 按位置传递给策略函数的参数对象有序列表。零参数函数请传入空数组 `[]`。 |

### 服务端消息

#### 连接确认

握手成功后立即发送一次。

```json
{
  "status": "connected",
  "message": "Connected to Aster preview endpoint"
}
```

#### 评估成功

```json
{
  "status": "success",
  "message": null,
  "result": true,
  "executionTime": 6
}
```

#### 评估错误

```json
{
  "status": "error",
  "message": "Policy function 'isEligible' not found in module 'Loan.Approval'",
  "result": null,
  "executionTime": null
}
```

### 服务端消息字段

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `status` | `string` | `connected`、`success` 或 `error` 之一。 |
| `message` | `string \| null` | 人类可读的描述。`connected` 和 `error` 状态非 null；`success` 时为 `null`。 |
| `result` | `any \| null` | 策略函数返回的值。匹配函数声明的返回类型。错误时为 `null`。 |
| `executionTime` | `number \| null` | 挂钟评估时间（毫秒）。错误时为 `null`。 |

## 连接生命周期

1. 客户端打开到 `ws://<host>/ws/preview` 的 WebSocket 连接。
2. 服务器发送 `{ "status": "connected" }` 消息。
3. 客户端发送 JSON 评估请求。
4. 服务器以 `{ "status": "success" }` 或 `{ "status": "error" }` 响应。
5. 步骤 3-4 在会话期间重复。
6. 任一方可在任何时候关闭连接。

## 示例

<CodeGroup>

```js [Browser]
const ws = new WebSocket('wss://policy.aster-lang.dev/ws/preview');

ws.addEventListener('open', () => {
  console.log('WebSocket open — awaiting connected message');
});

ws.addEventListener('message', (event) => {
  const msg = JSON.parse(event.data);

  if (msg.status === 'connected') {
    // Send an evaluation request once connected
    ws.send(JSON.stringify({
      policyModule:   'Loan.Approval',
      policyFunction: 'isEligible',
      context: [
        {
          applicantAge:    30,
          annualIncome:    75000,
          creditScore:     720,
          requestedAmount: 25000,
        },
      ],
    }));
  } else if (msg.status === 'success') {
    console.log('Result:', msg.result);
    console.log('Execution time:', msg.executionTime, 'ms');
    ws.close();
  } else if (msg.status === 'error') {
    console.error('Evaluation error:', msg.message);
    ws.close();
  }
});

ws.addEventListener('close', (event) => {
  console.log('Connection closed', event.code, event.reason);
});
```

```js [Node.js (ws)]
import WebSocket from 'ws';

const ws = new WebSocket('wss://policy.aster-lang.dev/ws/preview');

ws.on('message', (data) => {
  const msg = JSON.parse(data.toString());

  if (msg.status === 'connected') {
    ws.send(JSON.stringify({
      policyModule:   'Loan.Approval',
      policyFunction: 'isEligible',
      context: [
        {
          applicantAge:    30,
          annualIncome:    75000,
          creditScore:     720,
          requestedAmount: 25000,
        },
      ],
    }));
  } else if (msg.status === 'success') {
    console.log('Result:', msg.result);
    ws.close();
  } else if (msg.status === 'error') {
    console.error('Error:', msg.message);
    ws.close();
  }
});

ws.on('error', console.error);
```

</CodeGroup>

## WebSocket 关闭码

| 码 | 含义 |
|------|---------|
| `1000` | 正常关闭 —— 客户端或服务器有意关闭连接。 |
| `1011` | 非预期的服务器错误 —— 内部引擎故障。 |
