# 工作流状态

获取工作流当前的物化状态。该状态由工作流的事件日志推导得出，可能由周期性快照辅助以加速读取。当你需要最新的状态和结果而无需拉取完整事件历史时，使用此端点。

## 端点

`GET /api/v1/workflows/{workflowId}/state`

## 必需角色

`MEMBER`

## 请求头

| 请求头 | 值 | 必需 |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | 是 |
| `X-Tenant-ID` | 租户标识符字符串 | 是 |

## 路径参数

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `workflowId` | `string` | 工作流的唯一标识符。 |

## 响应体

```json
{
  "workflowId": "wf-abc123",
  "status": "COMPLETED",
  "lastEventSeq": 5,
  "result": {
    "eligible": true,
    "approvedAmount": 25000
  },
  "snapshot": {
    "intermediateState": "..."
  },
  "snapshotSeq": 3,
  "createdAt": "2024-01-15T10:29:58Z",
  "updatedAt": "2024-01-15T10:30:01Z"
}
```

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `workflowId` | `string` | 工作流的唯一标识符。 |
| `status` | `string` | 当前生命周期状态。参见下方 [状态值](#status-values)。 |
| `lastEventSeq` | `integer` | 最近一次应用事件的序列号。 |
| `result` | `any \| null` | 工作流产生的最终输出。当 `status` 进入终态（`COMPLETED`、`FAILED`、`COMPENSATED`、`COMPENSATION_FAILED`）时填充。非终态工作流为 `null`。 |
| `snapshot` | `object \| null` | 用于加速事件重放的不透明中间状态快照。若尚未创建快照则为 `null`。 |
| `snapshotSeq` | `integer \| null` | 创建快照时的序列号。当 `snapshot` 为 `null` 时也为 `null`。 |
| `createdAt` | `string` | 工作流创建时的 ISO 8601 时间戳。 |
| `updatedAt` | `string` | 最近一次状态变更的 ISO 8601 时间戳。 |

## 状态值

| 状态 | 终态 | 描述 |
|--------|----------|-------------|
| `READY` | 否 | 工作流已创建但尚未启动。 |
| `RUNNING` | 否 | 工作流正在执行。 |
| `COMPLETED` | 是 | 工作流成功完成。`result` 已填充。 |
| `FAILED` | 是 | 工作流因不可恢复的错误终止。 |
| `COMPENSATING` | 否 | 工作流正在执行补偿（回滚）步骤。 |
| `COMPENSATED` | 是 | 补偿成功完成。 |
| `COMPENSATION_FAILED` | 是 | 补偿步骤也失败。可能需要人工介入。 |

## HTTP 状态码

| 状态 | 含义 |
|--------|---------|
| `200 OK` | 请求成功。返回当前工作流状态。 |
| `401 Unauthorized` | 缺少或无效的 Bearer token。 |
| `403 Forbidden` | Token 有效但调用者缺少 `MEMBER` 角色，或工作流属于其他租户。 |
| `404 Not Found` | 未找到给定 `workflowId` 的工作流。 |
| `500 Internal Server Error` | 非预期的引擎故障。 |

## 示例

<CodeGroup>

```bash [curl]
curl -X GET "https://policy.aster-lang.dev/api/v1/workflows/wf-abc123/state" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const workflowId = 'wf-abc123';
const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/workflows/${workflowId}/state`,
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const state = await response.json();

if (state.status === 'COMPLETED') {
  console.log('Workflow result:', state.result);
} else if (state.status === 'FAILED') {
  console.error('Workflow failed. Last event sequence:', state.lastEventSeq);
}
```

</CodeGroup>
