# Workflow-Ereignisse

Rufen Sie die geordnete Sequenz von Ereignissen ab, aus denen die Ausführungshistorie eines Workflows besteht. Ereignisse sind die fundamentale Einheit des Event-Sourcing-Modells für Workflows — der aktuelle Zustand eines beliebigen Workflows kann jederzeit durch Wiedergabe seines Event-Logs von Anfang an rekonstruiert werden.

## Endpunkt

`GET /api/v1/workflows/{workflowId}/events`

## Erforderliche Rolle

`MEMBER`

## Header

| Header | Wert | Erforderlich |
|--------|-------|----------|
| `Authorization` | `Bearer <token>` | Ja |
| `X-Tenant-ID` | Mandanten-Identifikator-String | Ja |

## Pfad-Parameter

| Parameter | Typ | Beschreibung |
|-----------|------|-------------|
| `workflowId` | `string` | Der eindeutige Bezeichner des Workflows. |

## Query-Parameter

| Parameter | Typ | Erforderlich | Beschreibung |
|-----------|------|----------|-------------|
| `fromSeq` | `integer` | Nein | Nur Ereignisse mit einer Sequenznummer größer oder gleich diesem Wert zurückgeben. Standard ist `0` (alle Ereignisse). Nutzen Sie dies, um nach neuen Ereignissen ab einer bekannten Position zu pollen, ohne die vollständige Historie erneut abzurufen. |

## Response-Body

Die Antwort ist ein JSON-Array von Ereignis-Objekten, aufsteigend nach Sequenznummer sortiert.

```json
[
  {
    "sequence": 1,
    "workflowId": "wf-abc123",
    "eventType": "WORKFLOW_STARTED",
    "payload": {},
    "occurredAt": "2024-01-15T10:30:00Z"
  },
  {
    "sequence": 2,
    "workflowId": "wf-abc123",
    "eventType": "POLICY_EVALUATED",
    "payload": {
      "policyModule": "Loan.Approval",
      "policyFunction": "isEligible",
      "result": true,
      "executionTimeMs": 6
    },
    "occurredAt": "2024-01-15T10:30:00Z"
  },
  {
    "sequence": 3,
    "workflowId": "wf-abc123",
    "eventType": "WORKFLOW_COMPLETED",
    "payload": {
      "finalResult": true
    },
    "occurredAt": "2024-01-15T10:30:01Z"
  }
]
```

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `sequence` | `integer` | Monoton steigende Sequenznummer innerhalb des Workflows. Lücken weisen auf fehlende oder verdichtete Ereignisse hin. |
| `workflowId` | `string` | Bezeichner des zugehörigen Workflows (spiegelt den Pfad-Parameter). |
| `eventType` | `string` | Ereignisklassifizierung (z. B. `WORKFLOW_STARTED`, `POLICY_EVALUATED`, `WORKFLOW_COMPLETED`, `COMPENSATION_STARTED`). |
| `payload` | `object` | Ereignisspezifische Daten. Die Struktur variiert je `eventType`. |
| `occurredAt` | `string` | ISO 8601 Zeitstempel, wann das Ereignis aufgezeichnet wurde. |

## HTTP-Statuscodes

| Status | Bedeutung |
|--------|---------|
| `200 OK` | Anfrage erfolgreich. Gibt ein Array zurück (kann leer sein, wenn `fromSeq` über dem letzten aufgezeichneten Ereignis liegt). |
| `400 Bad Request` | Fehlerhafter `fromSeq`-Parameter. |
| `401 Unauthorized` | Fehlender oder ungültiger Bearer-Token. |
| `403 Forbidden` | Token ist gültig, dem Aufrufer fehlt jedoch die `MEMBER`-Rolle, oder der Workflow gehört einem anderen Mandanten. |
| `404 Not Found` | Kein Workflow mit der angegebenen `workflowId` gefunden. |
| `500 Internal Server Error` | Unerwarteter Engine-Fehler. |

## Beispiele

<CodeGroup>

```bash [curl]
# Fetch all events for a workflow
curl -X GET "https://policy.aster-lang.dev/api/v1/workflows/wf-abc123/events" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"

# Poll for new events after sequence 42
curl -X GET "https://policy.aster-lang.dev/api/v1/workflows/wf-abc123/events?fromSeq=43" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: acme-corp"
```

```js [JavaScript]
const workflowId = 'wf-abc123';

// Fetch all events
const response = await fetch(
  `https://policy.aster-lang.dev/api/v1/workflows/${workflowId}/events`,
  {
    headers: {
      Authorization: 'Bearer <token>',
      'X-Tenant-ID': 'acme-corp',
    },
  }
);

const events = await response.json();

// Poll for new events after a known sequence
async function pollNewEvents(workflowId, lastSeq) {
  const params = new URLSearchParams({ fromSeq: String(lastSeq + 1) });
  const res = await fetch(
    `https://policy.aster-lang.dev/api/v1/workflows/${workflowId}/events?${params}`,
    {
      headers: {
        Authorization: 'Bearer <token>',
        'X-Tenant-ID': 'acme-corp',
      },
    }
  );
  return res.json();
}
```
