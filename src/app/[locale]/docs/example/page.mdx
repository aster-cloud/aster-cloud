# MDX Pipeline Smoke Test

This page exists only to prove the MDX pipeline compiles and renders end-to-end on Cloudflare Workers via OpenNext. It is the validation target for [`cloud-docs-subsite.md` §8](/) Session 1.

If you can read this with code highlighting, GFM tables, and heading anchors all working, the foundation is good and real docs can be migrated in Session 3.

## Markdown basics

Inline **bold**, _italic_, `code`, and [link](/en) all work.

Lists nest cleanly:

- Compile-time MDX → static RSC payload
- Worker runtime serves static HTML
  - No runtime Shiki, no fs access
  - Shiki grammars baked at build
- Cloudflare CDN handles edge cache
